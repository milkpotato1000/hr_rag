른 신청이 이미 있는지도 대조한다. 하루 사용을 반차로 바꾸거나 반차를 하루 사용으로 바꾸려는 
경우에는 AN-03@v4의 단위에 맞게 현재 신청 내용을 확인하되, 신청자의 의사가 확인되지 않은 
상태에서 차감량을 먼저 바꾸지 않는다. 화면의 오전·오후 선택값이 뒤바뀌어 보이는 오류와 실제 
희망 시간이 바뀐 요청은 처리 이유를 구별하여 남긴다. 신청자가 날짜를 잘못 말한 뒤 바로 정정
한 경우에는 최신 의사를 확인할 수 있는 회신을 연결하고, 이전 표현만을 근거로 추가 휴가를 사용
한 것으로 표시하지 않는다. 변경 요청이 여러 번 이어지더라도 최초 신청과 각 변경의 관계를 유
지하여 마지막 값만 남겨 중간 확인 과정을 알 수 없게 만들지 않는다.
변경 과정에서 당일 긴급 사유가 새로 전달되면 AN-06@v4의 접수 예외와 연결하여 확인한다. 다
만 날짜를 바꾸었다는 사실만으로 모든 변경을 긴급 신청으로 처리하지 않는다. 변경 후 기록과 원
래 기록이 동시에 표시되는 경우에는 어떤 기록이 현재 확인 대상인지 신청자에게 알려 중복 사용
으로 오인되지 않게 한다. 반영이 끝나지 않은 화면을 보고 추가 변경을 요청한 경우에는 그 화면
의 기준 시점과 최신 요청을 대조한 뒤 처리 순서를 정리한다.
AN-10 취소 요청과 사용 기록 정리
취소 요청을 받으면 대상 신청의 기록 번호와 사용 날짜를 확인하여 신청자가 철회하려는 범위를 
분명히 한다. 여러 날짜의 요청 중 일부만 취소하려는 경우에는 유지하는 날짜와 취소하는 날짜를 
나누어 기록하고, 전체 신청을 일괄 삭제하지 않는다. 실제 사용 여부가 아직 확인되지 않았거나 사
용 내역 반영이 지연되고 있으면 담당자는 신청 취소 의사와 기존 사용 사실의 확인을 구분해 처리
한다. 취소 요청이 접수되었다는 이유만으로 모든 차감이 이미 복구되었다고 안내하지 않으며, 반
영된 수치와 아직 대조 중인 수치를 구분한다. 중복 입력된 기록 하나를 정리하는 경우에는 동일 
신청의 다른 정상 기록이 남아 있는지를 먼저 확인하여 정상 사용까지 취소되지 않게 한다. 정리 
후에는 대상 기록과 현재 상태를 신청자가 식별할 수 있도록 안내하고, 정리 사유가 취소인지 중복 
입력의 수정인지 표시한다.
취소라는 표현 없이 일정 문의만 들어온 경우에는 문의 내용을 즉시 철회 의사로 기록하지 않는다.
 반대로 신청자가 취소 의사를 분명하게 밝혔지만 기록 번호를 기억하지 못하는 경우에는 확인 가
능한 날짜와 기존 내역으로 대상 요청을 찾는다. 기록 번호를 다시 제출하지 못했다는 사유를 새로
운 취소 제한으로 만들지 않고, 어떤 신청을 대상으로 처리했는지 확인 내용을 남긴다.
AN-11 접속 장애와 자료 불일치의 분리 처리
시스템 장애로 신청 내용이나 접수 결과를 볼 수 없는 경우에는 담당자가 사용 희망일, 사용 단위, 
신청자가 알린 상황과 시점을 임시 기록으로 남긴다. 이는 AN-04@v4의 통상 신청 방식이 정상 
작동하지 않을 때 기록의 연속성을 유지하기 위한 예외이며, 원래 신청 기한이나 긴급 사유 조건을 
없애는 절차가 아니다. 복구 후에는 이미 생성된 신청을 먼저 찾아 중복 입력을 피하고, 임시 기록
으로만 남아 있는 경우에는 최초 전달 시점과 복구 입력 시점을 함께 보존한다. 장애 중 화면에 보
인 합계가 복구 후 값과 다르면 담당자는 장애 당시 화면의 정보와 실제 원장 반영을 분리해 대조한
다. 화면이 열리지 않았다는 사실만으로 사용 기록이 삭제되었다고 보거나, 복구 뒤 표시되는 내역
을 모두 새로운 신청으로 간주하지 않는다. 확인되지 않은 부분은 자료 불일치로 표시하여 AN-02
