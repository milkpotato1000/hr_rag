 신청자가 보았다고 설명한 시점은 별도 항목으로 남겨, 이후 값이 달라져도 처음 문의의 이유를 확
인할 수 있게 한다. 이 과정에서 담당자는 AN-01@v4에 없는 발생 조건이나 개인별 가산 일수를 
임의로 입력하지 않고, 원자료가 확인되지 않는 부분을 미확인 항목으로 표시한다.
확인에 사용한 인사 기록 중 입사 정보나 근무 정보가 잘못 연결되어 있으면 오류가 의심되는 값, 
확인에 사용한 출처, 정정 요청의 진행 상태를 기록한다. 단순히 계산 결과가 예상보다 작다는 이유
로 발생 내역을 직접 늘리거나, 예상보다 크다는 이유로 근거 없이 줄이지 않는다. 원자료가 정정되
면 정정 전 계산에 사용한 값과 정정 후 값을 구분하여 다시 대조한다. 동일한 원자료를 여러 화면
에서 참조하고 있을 경우에는 어느 화면까지 새 값이 반영되었는지 확인하고, 아직 반영되지 않은 
화면의 수치를 최종 결과로 안내하지 않는다. 원자료의 오류 확인과 계산 결과의 반영이 서로 다른
 담당 업무이면 양쪽의 확인 내용을 연결하되, 담당자 사이에서 자료를 넘겼다는 사실만으로 정정 
완료 상태를 표시하지 않는다. 문의자에게는 확인된 사항과 추가 확인 중인 사항을 나누어 안내하
며, 아직 확인하지 못한 출근 기록을 개근 사실로 가정하여 결과를 설명하지 않는다.
발생 내역과 사용 내역이 함께 달라진 문의에서는 두 차이를 따로 정리한다. 예를 들어 발생 기록
의 정정이 필요한 상황에서 동시에 중복 차감이 발견되면, 하나의 합계 수정으로 두 사유를 덮지 않
고 각각의 변경 근거를 연결한다. 이미 안내한 합계가 잠정 값이었다면 새 안내에도 이전 안내와 
비교할 수 있는 기준 시점을 표시한다. 정정 결과를 전달한 뒤 다시 문의가 들어오면 과거 문의 번
호와 현재 문의 번호를 연결하고, 새롭게 제기된 차이가 무엇인지 먼저 확인한다. 동일한 설명을 다
시 요구하는 대신 기존 대조 자료에서 확인할 수 있는 항목은 재사용한다. 다만 이전 문의가 다른 
기간이나 다른 신청 건에 관한 것이었다면 그 결과를 그대로 적용하지 않고 대상 기간을 구분한다.
 관련 자료에 없는 보상이나 소멸 여부가 함께 질문된 경우에는 발생·사용 수치 확인과 별도 항목으
로 남기고, 확인 중인 계산 값을 그러한 처리의 근거로 사용하지 않는다.
AN-03 반차의 사용 단위
연차는 오전 또는 오후 반차로 나누어 사용할 수 있다. 반차 1회는 연차 0.5일로 차감한다.
반차 신청 내역에는 오전과 오후 중 선택한 구분을 기록한다. 하루 사용과 반차 사용이 같은 날 함
께 표시되면 담당자는 실제 신청 의도를 확인하여 중복 여부를 정리하며, 선택 오류를 다른 휴가 제
도의 분할 허용으로 해석하지 않는다.
