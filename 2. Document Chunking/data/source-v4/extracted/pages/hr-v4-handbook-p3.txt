존재하지 않는 경우에만 임시 기록과 연결하여 입력한다. 임시 기록의 작성만을 이유로 신청 기한
이 연장되었다고 안내하거나 팀장 승인 없이 사용이 확정되었다고 통지하지 않는다. 기한 또는 승
인 여부의 판단이 필요한 항목은 원래 사실관계가 보이도록 남겨 BD-03@v4의 절차에서 확인한
다. 동일 내용을 반복 제출한 흔적이 있을 때에는 신청자에게 대표 요청을 확인하고 나머지 기록을
 중복으로 연결하되, 중복 표시가 휴가 일수의 추가 사용이나 신청 취소를 뜻하지 않도록 처리 상태
를 설명한다.
BD-06 날짜 변경과 취소 의사 확인
신청자가 사용 날짜를 바꾸려는 경우에는 어느 요청을 어떤 날짜로 바꾸려는지 확인하고 변경 전
후 값을 함께 남긴다. 원래 날짜를 유지한 채 설명만 바로잡는 것인지, 실제 사용 날짜를 변경하는 
것인지 구분한다. 다만 신청자가 문의 과정에서 여러 날짜를 예로 들었을 뿐 변경 의사를 확정하지
 않은 경우에는 문의 내용을 새 신청으로 등록하지 않는다. 변경이 확정된 요청은 BD-04@v4의 
현재 처리 상태와 연결하여 검토·통지하며, 승인 여부를 문의했다는 이유만으로 승인 완료 표시를 
붙이지 않는다. 취소 의사가 전달되면 대상 요청을 식별하여 현재 사용 기록과 대조하고, 이미 기록
이 반영된 경우에는 어떤 기록을 바로잡아야 하는지 확인한다. 취소 요청을 받았다는 사실과 실제 
기록 정리가 끝났다는 사실을 분리해 안내하고, 담당자의 확인이 끝나지 않은 값을 개인별 잔여 일
수로 단정하지 않는다.
BD-07 생일 축하 포인트의 관계
생일 축하 포인트 지급 내역은 생일 특별휴가의 신청 번호와 별개로 식별한다. 포인트를 받았다는 
문의가 휴가 승인 확인으로 접수되면 문의 목적을 먼저 구분하고, 휴가에 관한 내용은 BD-03@v4
의 승인 기록에서 확인한다. 지급 내역 화면을 휴가 승인서 대신 첨부하거나 두 상태를 같은 항목
으로 합치지 않는다.
