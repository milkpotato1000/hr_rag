용 건으로 계산하지 않고 날짜와 사용 단위를 대조한다. 담당자가 요청을 찾기 위해 추가 설명을 
문의할 때에는 이미 시스템에서 확인되는 정보를 반복 제출하도록 요구하지 않으며, 필요한 정정 
내용만 신청자가 확인할 수 있게 제시한다.
AN-05 검토 내용의 연결과 처리 통지
담당자는 접수된 연차 신청을 해당 직원의 사용 기록과 연결할 때 기록 번호, 사용 날짜, 사용 단위
를 차례로 대조한다. 같은 직원이 같은 날 다른 종류의 휴가를 문의한 경우에도 문의 기록을 곧바
로 사용 기록으로 옮기지 않는다. 이미 반영된 신청과 새 요청이 겹치면 중복 제출인지 날짜 변경
인지 구분하기 위해 신청자에게 현재 의사를 확인한다. 확인 과정에서는 어떤 기록을 비교하고 있
는지 신청자가 알 수 있도록 대상 날짜와 요청의 식별 정보를 제시하며, 개인 사유의 상세한 설명을
 새 자격 조건으로 요구하지 않는다. 요청에 누락된 정보가 발견되면 누락 항목과 확인 방법을 안
내하고, 내용 확인을 기다리는 상태와 신청이 없었던 상태를 구분한다. 최초 제출 사실이 남아 있는
데 단순 보완을 이유로 그 시점을 지우거나, 보완 입력 날짜를 원래 신청 날짜처럼 바꾸지 않는다.

검토 중에는 확인이 끝난 정보와 아직 문의 중인 정보를 분리하여 표시한다. 사용 기록의 수치가 
서로 다르면 담당자는 어느 자료에서 차이가 생겼는지를 찾고, 신청자의 정정 요청과 원래 기록을 
함께 남긴다. 시스템의 상태 코드가 다른 화면과 다르게 보이는 경우에는 코드 이름만 보고 사용이
 확정되었거나 취소되었다고 단정하지 않는다. 해당 상태가 접수, 정보 확인, 사용 기록 반영 중 어
느 과정을 나타내는지 확인하고 그 의미를 안내한다. 이미 팀장에게 알린 긴급 신청이라면 그 통지
 사실이 접수 기록에 연결되어 있는지 별도로 살핀다. 다만 통지 내용을 담당자가 열람하지 못했다
는 이유만으로 통지 자체가 없었다고 기록하지 않고 확인되지 않은 항목으로 남긴다. 여러 담당자
가 같은 신청을 순차적으로 확인할 때에는 앞서 확인한 원자료의 위치와 미확인 사항을 전달하여 
동일 문의가 반복되지 않도록 한다. 담당자 변경은 신청의 새로운 발생이나 별도 휴가 사용을 뜻하
지 않는다.
신청 관련 기록이 정리되면 신청자에게 현재 처리 상태, 반영된 날짜와 사용 단위, 남아 있는 확인 
사항을 구분하여 전달한다. 기록에 대한 안내에는 그것이 접수 확인인지 정보 정정 완료인지 실제 
사용 내역 반영인지 드러나야 한다. 이 장에 명시하지 않은 별도 승인권자를 추가하거나 담당자의 
내부 대조를 새로운 사용 자격 심사로 표시하지 않는다. 신청자가 통지 내용이 원래 요청과 다르다
고 알리면 통지문과 원래 제출본을 먼저 대조한다. 잘못 안내한 항목이 발견되면 정정 안내에 변경
한 항목과 변경하지 않은 항목을 함께 표시하여 전체 요청이 바뀐 것처럼 보이지 않게 한다. 결과

모든 정정 요청의 철회로 확대해 해석하지 않는다. 문의가 끝난 뒤에도 정정이 필요할 수 있으므로
 관련 기록의 식별 관계를 유지하고, 새로운 문의가 들어오면 어느 이전 기록과 이어지는지를 확인
하여 처리한다.
