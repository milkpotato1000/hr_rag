류가 확인되면 원래 안내와 정정 안내를 연결하고, 이미 확인한 내용까지 새로 제출해야 하는 것처
럼 요청하지 않는다. 문의가 여러 시험이나 여러 날짜를 포함했다면 확인을 마친 대상과 나머지 대
상을 구분하여 남긴다. 담당자가 작성한 안내는 그 시점에 확인한 기록을 설명하는 것이며, 시험 합
격 여부나 비용 지원 여부처럼 이 장에서 정하지 않은 내용을 함께 확정하는 자료로 사용하지 않는
다.
ED-05 시험 일정 변경과 신청 정정
시험 일정이 변경되었다는 연락을 받으면 담당자는 변경 전 일정, 새로 전달된 일정, 신청자가 실제
로 바꾸려는 사용 희망일을 서로 연결한다. 시험 일정이 바뀌었다는 사실만으로 휴가 신청 날짜도 
자동으로 같은 방식으로 바꾸지 않고 신청자의 현재 의사를 확인한다. 일정 안내의 오입력인지 시
험 주관 측 일정의 변경인지 신청자의 응시 계획 변경인지 확인 가능한 범위에서 사유를 구분하되, 
그 구분을 새로운 자격 심사 항목으로 만들지 않는다. 같은 시험의 여러 회차가 함께 표시되어 있
으면 어느 회차와 연결된 요청인지 확인하고 다른 회차의 날짜를 잘못 참조하지 않도록 한다. 원래
 요청이 아직 정보 확인 단계이면 기존 요청에 정정 내용을 연결하고, 이미 안내가 전달된 상태이면
 안내 내용과 변경 요청을 함께 확인하여 현재 처리 대상을 분명히 한다. 통상적으로는 시스템의 
기존 신청을 찾아 변경 관계를 남기지만 해당 기록이 조회되지 않는 경우에는 신청자를 다시 접수
시키기 전에 확인 가능한 기록 번호나 전달 내용을 이용해 원래 요청을 찾는다.
시험 안내 화면에는 정정된 일정이 나타나고 휴가 신청 화면에는 이전 날짜가 남아 있는 사례가 있
을 수 있다. 이때 두 화면의 날짜 차이는 곧바로 두 건의 휴가 신청이 있다는 뜻이 아니다. 한 화면
의 안내가 먼저 바뀌고 신청자의 실제 날짜 변경 의사는 아직 확인되지 않은 상태일 수도 있다. 시
험 정보의 변경과 휴가 신청의 변경을 구별하면 원래 신청을 유지하면서도 새 문의의 이유를 설명
할 수 있다. 이 사례는 ED-03@v4의 정보 구분을 설명하는 것으로, 시험 일정 변경 시 추가 휴가를
 부여하거나 기존 사용량을 자동 복구한다는 별도 규칙을 뜻하지 않는다.
ED-06 응시 계획 취소와 요청 상태의 정리
응시 계획을 취소했다는 연락을 받으면 담당자는 취소하려는 교육휴가 요청을 먼저 식별한다. 시
험 접수만 취소한 것인지 휴가 신청도 취소하려는 것인지 구분하고, 신청자가 아직 결정하지 못한 
문의를 확정된 취소로 기록하지 않는다. 확인된 취소 의사는 원래 신청과 연결하여 남기며, 다른 시
험에 관한 요청이나 이미 별도로 관리되는 휴가 기록까지 일괄 삭제하지 않는다. 신청 날짜를 잘못
 선택하여 다시 입력하려는 경우에는 날짜 정정으로 처리할 수 있는지 ED-05@v4의 변경 관계를 
확인한다. 취소 후 새로운 신청이 접수되면 두 요청의 관계를 식별하되, 새로운 요청의 시험과 날짜
는 실제 입력된 내용으로 확인한다. 취소 통지에는 정리한 대상과 현재 기록 상태를 적고, 사용량의
 표시가 아직 이전 값이면 그 차이를 확인 중인 항목으로 구분한다. 취소 의사를 접수했다는 사실
만으로 잔여 일수가 복구되었다고 안내하지 않으며, 반영된 기록을 확인한 후 그 결과를 설명한다. 
신청자가 취소 요청을 철회하면 이전 요청을 조용히 되살리지 않고 철회 의사와 현재 처리 상태를 
대조한다. 이미 완료된 정리와 아직 진행 중인 정리를 구분하여 후속 담당자에게 넘기고, 정정 이력
을 남겨 같은 취소가 반복 반영되지 않게 한다.
