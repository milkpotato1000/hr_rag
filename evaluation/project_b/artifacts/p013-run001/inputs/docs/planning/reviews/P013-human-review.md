# P013 사람이 확인할 내용 — 승인 대기

정답과 평가기 시험의 기대값을 확인하는 문서입니다. run004 화면 확인은 끝났으므로 다시 확인하지 않아도 됩니다. 기술 설정과 호출 한도는 Codex가 준비합니다.

## 확인할 세 가지

1. 아래 질문별 필수 사실은 빠지면 감점하고, 보충 정보는 생략해도 감점하지 않는 구분이 적절한가요?
2. 주장 추출·근거 판정·정답 매칭 예시의 기대 결과가 맞나요?
3. 실제 제공 근거에 대한 Faithfulness와 필수 정답에 대한 Correctness를 분리하는 채점 기준이 맞나요?

확인한 범위에 대해 **“P013 정답지와 검증 기대값 승인”** 또는 **“gtXX의 … 수정”**처럼 답하면 됩니다. 일부만 읽었다면 항목을 지정할 수 있습니다. 열람이나 계속 진행 요청은 데이터 승인이 아닙니다. 기존 gt01 첫5개 승인과 판단 위임은 보존하며 새 전체57개 사람 승인으로 확대하지 않습니다.

가상 HR 규정 학습용 기준의 승인입니다. 실제 회사 제도나 Qwen 성능을 승인하는 것이 아닙니다.

## F. 채점 기준

- 맞힌 필수 사실 수 / 생성한 핵심 사실 수 = Precision, 맞힌 필수 사실 수 / 필수 정답 수 = Recall입니다. F1은 둘을 함께 반영합니다.
- 중복은1회 계산합니다. partial에 자동 반 점수를 주지 않습니다. uncertain은 점수 보류로 표시합니다.
- 참 보충은 핵심 분모·가산에서 제외합니다. 틀린 보충은 별도 오류이며 전체 정답으로 표시하지 않습니다.
- Faithfulness·Neutral·Contradiction은 보충을 포함한 생성 사실 전체를 봅니다. 판정 실패가 있으면 세 비율은 확정하지 않습니다.
- gt09/10은 빈 정답을 이유로100점을 주지 않고 보류 적절성과 금액 발명을 따로 확인합니다.
