문서 준비

샘플 또는 업로드 원문을 선택해 snapshot을 만듭니다. 업로드 자체는 파싱 성공을 뜻하지 않습니다.

내 파일 업로드

Google Drive 단일 문서

drive.readonly는 한 파일보다 넓은 읽기 권한입니다. 폴더·다른 웹하드는 미지원이며 로그인은 CLI에서 합니다. 링크는 이 입력창에만 유지합니다.

01

생성 모델

등록된 연결을 선택하세요. API key와 endpoint는 브라우저에서 바꾸지 않습니다.

모델 설정을 복제해 새로 저장
로컬 모델 출처 · 고급 설정

Ollama alias에서 HF 출처를 추측하지 않습니다. 본인이 확인한 모델 정보만 입력하세요. CLI에서 ollama list / ollama show 모델명으로 정보를 확인할 수 있지만 이 화면은 조회·다운로드하지 않습니다.

기존 설정과 평가 모델은 보존합니다. 저장은 live 검증 성공이 아닙니다.

02

청킹

경계를 정하는 방식과 숫자를 따로 바꾸고, 청크에서 원문 위치를 확인하세요.

긴 섹션은 최대 크기에 맞춰 재분할합니다. 제목 경로는 metadata이며 원문 인용에 임의로 추가하지 않습니다.

저장 경계 실험 · 다섯 청킹 방식

경계 생성과 검색 색인을 따로 실행합니다. 의미·LLM 청킹은 기본 미리보기입니다.

파생은 저장 단위·모델 identity를 보존합니다. LLM은 경계를 유지하며 크기를 넘으면 실패합니다.

검색·생성 설정은 아래 선택값으로 고정합니다. 경계 모델 재실행 0회. Dense/Hybrid 임베딩 계산은 별도이며 정답 평가기는 미연결입니다.

03

검색과 전달 문맥

top-k 후보 전체가 답변 모델에 전달되는 것은 아닙니다. 예산에 포함된 청크를 대조하세요.

이 분량은 청크 문자 수의 합입니다. 모델 token window 및 전체 프롬프트 토큰과 다르며 정확한 환산을 하지 않습니다.

04

답변과 원문 인용

인용 원문을 펼쳐 보여 줍니다. 인용이 있어도 모든 조건을 답했다는 뜻은 아닙니다.

아직 답변 결과가 없습니다. 먼저 검색·입력 미리보기를 실행하세요.
05

같은 문서·질문으로 비교

설정 2~4개를 같은 snapshot에 적용합니다. 바뀐 축과 실패 행도 함께 봅니다.

미리보기는 모델 요청 0회입니다.

답변 평가기는 미연결입니다. 검색 지표는 등록 qrels의 값과 N/A 사유를 확인하세요. N/A는 0점이 아닙니다.
06

고정 후보 리랭킹

검색 후보 N개를 한 번 고정하고 순위만 바꿉니다. 후보 밖의 누락은 복구하지 못합니다.

Raw score는 확률이 아닙니다. 모델 사이 점수를 합산하지 않습니다. 길이 초과 시 새 후보 실험을 준비하세요. qrels/facts 미등록은 N/A이며 답변 평가와 다릅니다.
