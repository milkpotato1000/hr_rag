# Checkpoint 내용 양식

workflow_control.py pause/resume이 생성한 상태 필드를 유지하며 아래를 이어 적는다.
다른 역할의 기록을 덮어쓰거나 과거 실패를 제거하지 않는다.

- 사용자 요청과 중지 범위:
- 완료한 것과 확인한 증거:
- 구현했으나 검증 전인 것:
- 실패/미완료/시작하지 않은 것:
- 현재 커밋과 채택 계획:
- 진행 중인 프로세스/외부 작업과 중단 확인:
- 로컬 저장/커밋/원격 전달 상태:
- 필요한 결정과 재개 후 첫 행동:

상태 기록만으로 프로세스가 실제 중단됐다고 주장하지 않는다.
