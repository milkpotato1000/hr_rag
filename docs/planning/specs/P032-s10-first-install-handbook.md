# P032 S10 · 설치 직후 같은 규정집으로 실습하기

## 준비 검토

dev ee988fe에서 설치 UI와 CLI가 같은 경로를 사용한다. 그러나 저장소 첫 화면은 이전 LangChain 서버를 현재 시작점으로 소개하고, 설치물의 HANDBOOK은 학습자에게 직접 PDF를 찾도록 안내한다. 현재 실험에 사용한 합성 문서는 저장소의 `2. Document Chunking/data/source-v4/output/pdf/hr-handbook.pdf`다.

## 구현과 검증

1. 공개 dev 브랜치의 README 첫 화면에서 현재 설치 안내와 규정집 실습으로 진입하게 한다. 기존 단계별 문서와 명령은 해당 단계의 재현 경로로 유지한다.
2. 새 wheel 설치와 독립 작업 폴더에서 동일한 합성 PDF를 선택해 시작할 수 있게 한다. 기본 예제와 자기 PDF 사용법을 명시하고 기존 init 호출과 사용자 문서를 보존한다. 배포하는 PDF를 원본과 해시로 대조하고 생성·배포 과정에서 사본이 달라지는 경우를 검출한다.
3. Codex와 Claude Code에 그대로 줄 수 있는 실습 요청과 수동 CLI 경로를 연결한다. 설치 → 예제 준비 → 생일휴가 신청 기한 검색 → 로컬 Qwen 4B 생성 실행 방법 → 페이지와 인용 확인 순서다. 로컬 기본값과 선택 API 설정을 구분한다.
4. 새 venv에 wheel을 설치하고 소스 트리 밖에서 안내대로 예제를 준비해 PDF 파싱·BM25 검색 후 BD-03, 1쪽과 신청 기한 원문을 확인한다. 기존 사용자 PDF의 보존과 기존 init 예제를 검사한다. 모델 생성은 S8 실측과 S9 화면 기록을 연결한다. Drive·평가기·유료 API·새 모델 다운로드는 보류한다. 실제 실행한 명령과 관찰값을 기록한 뒤 dev 검증 및 정상 push한다.
