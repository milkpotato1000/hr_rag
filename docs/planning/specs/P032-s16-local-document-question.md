# P032 S16 · 내 문서와 질문으로 실습 시작하기

## 준비 검토

dev 5f8a887의 pipeline_setup.setup은 handbook-sources.json과 생일휴가 승인권자 질문을 출력 명령에 고정한다. HANDBOOK은 다른 PDF를 쓸 때 파일을 직접 복사하고 예제 소스 JSON을 편집하도록 안내한다. 일반 pipeline과 serve의 소스 등록, 기존 파일 업로드·문서 검증 경로를 재사용한다.

## 구현과 완료 기준

1. 새 설치 실습 폴더에서 사용자가 자기 로컬 PDF와 질문을 지정하고 기존 모델·검색 설정으로 진행한다. 현재 지원하는 텍스트 형식은 기존 문서 처리기와 호환되게 한다. 명령에서 원문을 명시적으로 선택해 독립된 입력을 준비하며 JSON 편집이 필요 없어야 한다. 예제 규정집과 사용자의 원본 파일을 그대로 보존한다. 출처·표시 제목·합성 문서 여부를 알맞게 기록한다.
2. 선택한 문서와 질문이 생성된 pipeline 미리보기 및 학습 화면 초기값까지 이어지고 CLI와 UI에서 같은 소스·질문·설정을 확인할 수 있어야 한다. UI에서 질문을 바꿔 계속 실습할 수 있도록 한다. 기존 source manifest, 업로드와 예제 기본값도 유지한다. 준비 단계는 모델 호출·외부 전송 없이 진행한다.
3. 독립 wheel에서 저장소의 별도 합성 PDF와 해당 PDF에만 있는 근거·질문으로 검증한다. 샘플을 덮어쓰지 않고 공백이 있는 경로·제목·질문을 전달한다. 두 문서의 지문, 전달된 근거의 실제 원문·페이지, 기본 규정집 보존을 확인한다. BM25로 모델 호출 없이 근거를 확인하고 브라우저에서 소스·질문이 맞는지 대조한다. 원본 파일 누락·지원하지 않는 형식·기존 출력과 마주쳤을 때 입력을 보존한다. 개인 파일 사용이나 배포는 필요 없다.
4. Codex·Claude Code에 본인의 파일과 질문으로 요청하는 예시 및 직접 실행 명령을 설치 문서에 넣는다. Drive·평가기·유료 API·추가 실모델 호출은 보류한다. 기존 규정집과 S15 설정 경로의 회귀, 검증 기록 및 dev 정상 push까지 진행한다.
