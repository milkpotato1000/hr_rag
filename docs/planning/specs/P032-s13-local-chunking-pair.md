# P032 S13 · 같은 질문에 대한 로컬 Qwen 실답변 비교

## 준비 검토

dev 3697764의 S12는 동일 질문의 청킹 비교에 합성 답변을 사용했다. 실제 답변 두 개는 질문이 달랐다. S11의 고정 청킹 실답변과 원본 실행을 대조할 수 있고 S12 practice.py가 이 실행을 임시 폴더에서 복사했다. 다른 컴퓨터의 학습자도 읽을 수 있도록 비교 결과는 저장소에 남긴다.

## 범위와 완료 기준

1. S11의 승인권자 질문, 배포 PDF, 기존 Ollama Qwen 4B, BM25, 리랭커 끔, 후보·K·문맥 예산, 생성 지시와 옵션을 고정한다. 기존 실답변·근거와 요청 기록을 읽고 해시를 확인한다. 고정 400/80에서 재귀 400/80으로 바꾸며 생성 입력의 문맥은 청킹에 따라 달라질 수 있다. 모델 digest와 정규화한 요청 옵션·질문·원문 해시, 패키지 버전 및 호출 경로 차이도 보고한다. 기존 자료로 동일성을 확인할 수 없는 값은 미확인으로 표시한다.
2. 독립 설치된 정상 pipeline 경로에서 현재 PDF를 검색하고 로컬 4B로 재귀 청킹 결과에만 신규 생성 최대 1회, 자동 재시도 0회. S11의 모델·소유 서버·자원·시간 상한과 종료 절차를 적용한다. 기존 고정 청킹 실행이 없거나 원문/모델이 달라지면 생성 전에 중지하고 원인을 기록한다. 기존 원본은 보존한다.
3. S12 비교로 양쪽의 실제 답변 전문, 승인 조항 첫 순위, 최종 문맥과 인용의 해당 문구·페이지를 대조한다. 레거시 설정이 불완전할 때 화면 판정은 유지하고 별도 검증한 항목을 기록한다. 답변 유무·정확성·근거 일치를 각각 원문과 대조하되 추가 평가 모델은 사용하지 않는다.
4. 학습 목차에서 양쪽 실답변과 인용을 볼 수 있는 비교 결과를 연결한다. 새 체크아웃에서도 저장된 비교 결과를 읽는 데 이전 실습 임시 경로·모델·인증이 필요 없어야 한다. 공개 학습 자료에 인증값·머신 경로를 담지 않는다. 한 질문에 대한 관찰로 범위를 명시하고 재생 호출 0회, 입력 보존 및 정상 dev push를 검증한다. Drive·평가기·유료 API·다운로드는 보류한다.
