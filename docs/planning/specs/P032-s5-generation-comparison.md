# P032 S5 · 같은 근거에서 생성 모델 비교하기

## 준비 검토

S4 dev b112c05는 설치본에서 Hybrid 후보 20개를 재정렬하고 최종 5개 문맥까지 확인했다. answer-from-rerank는 하나의 저장된 결과와 한 모델 설정을 받아 실행한다. 이 진입점을 재사용해서 학습자가 동일한 근거에서 생성 모델만 바꾸고 결과를 한 화면에서 읽을 수 있게 한다.

## 산출물 및 검증

1. 설치본에서 고정된 rerank 결과 하나를 선택하고, 이름을 붙인 로컬 또는 API 생성 프로필 둘 이상에 대해 별도 출력 경로로 preview 및 선택 실행하는 절차를 제공한다. 기본은 미리보기다. 기존 answer-from-rerank의 명시 실행·빈 문맥 보류·provider별 요청 규칙을 유지한다. 검증용으로 실제 보유한 모델은 기존 로컬 Qwen 4B 하나다.
2. 같은 입력에서 나온 결과 파일을 읽어 모델별 답변, 인용 원문·페이지, 완료·보류·실패·미실행, 관측 토큰과 지연을 나란히 보여준다. 재사용 가능한 패키지 CLI와 학습 UI의 별도 실험 메뉴에 연결한다. 비교 보기 자체는 모델·검색·리랭커 호출 0회다. 출력이 없는 미리보기는 빈 결과로 명시한다. 자동 평가 점수는 부여하지 않는다.
3. 비교 가능 여부는 원래 질문, 동일 source/parent, 순서·내용이 같은 전달 청크와 공통 업무 지시를 확인한다. 공급자·모델·모델별 요청 형식 차이는 표시한다. 입력이 다르면 동일 조건 비교로 표시하지 않는다. 과거 결과·중복 입력·부분 실패·비용과 토큰 미측정을 처리하고, UI는 기존 workspace 허용 경로·HTML escaping 정책을 사용한다. API 키와 hidden thinking은 출력이나 결과 파일에 포함하지 않는다.
4. 새 설치본의 실제 CLI로 S4 고정 문맥에서 두 설정을 미리보기한다. fixture로 서로 다른 완성 답변 2개·실패·미실행·문맥 불일치 표시를 실행하고 실제/예시를 명확히 구분한다. S4 원본이 보존된 것을 확인한 뒤 동일한 문맥으로 실제 로컬 4B 한 번만 생성해 PDF BD-03의 신청 기한과 인용을 대조한다. S3와 다른 문맥은 모델 간 품질 비교에 쓰지 않는다. API는 설정·미리보기만 허용한다. S3 단일호출·자동 재시도 0·시간/메모리·소유권/종료 한도를 사용한다.
5. 설치 가이드에서 사용자가 준비한 다른 로컬 모델 또는 선택한 유료 API로 같은 실험을 재현하는 방법을 안내한다. 독립 설치·CLI·UI 렌더링 및 주요 상태 회귀, 패키지 리소스와 예제 명령, 학습 목차 연결, dev 커밋·push를 검증한다. Drive·평가기·모델 다운로드·두 번째 실제 모델 호출은 보류한다.
