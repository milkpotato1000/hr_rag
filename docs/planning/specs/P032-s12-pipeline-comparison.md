# P032 S12 · 두 실행에서 설정·근거·최종 답변 비교

## 준비 검토

dev 9d8cbac에서 설치 화면이 새 질문의 답변과 인용을 생성했다. 현재 pipeline-replay는 한 실행을 열고 compare-answers는 같은 문맥에서 생성 모델을 비교한다. 학습자가 청킹·검색·리랭커 선택을 바꿔 저장한 두 실행에서는 어느 단계부터 결과가 달라졌는지 확인해야 한다.

## 범위와 완료 기준

1. 기존 실험 메뉴와 설치 CLI에서 저장된 통합 실행 두 개를 선택한다. 원문·질문이 같은지 먼저 확인한 다음 유효 청킹 파라미터, 검색 방식과 임베딩, 재정렬 모델·끔, K와 예산, 생성 프로필의 공통점과 변경점을 표시한다. 기존 재생과 결과 무결성 검증을 재사용한다.
2. 각 실행의 전달 순위·청크 원문/페이지, 최종 답변·실제 인용을 나란히 확인한다. 청킹이 다르면 서로 다른 ID의 지문도 원문 페이지·범위로 대조할 수 있게 한다. 질문·원문이 다르거나 여러 요인이 바뀐 경우 표시하고 특정 설정의 효과로 해석하지 않는다. 한쪽 실패·미실행이면 사용 가능한 단계와 상태를 표시한다.
3. 독립 wheel과 브라우저에서 같은 질문·같은 합성 규정집으로 청킹 또는 검색 설정 하나만 바뀐 두 실행을 대조한다. 시험 어댑터 결과는 합성으로 표시한다. S8·S11의 서로 다른 질문으로 단일 변수 실험이 성립하지 않는 경우도 확인한다. 저장소에 재생 가능한 원본이 없으면 동등한 비실행/시험 입력으로 검증하고 실제와 구분한다. 비교·재열기의 모델 호출 0회, 입력 보존, 변조·미등록 입력, 기존 생성 모델 비교와 단일 결과 재생 회귀를 검증한다.
4. 설치 가이드에 학습자가 한 변수만 바꿔 답변과 근거를 해석하는 예시를 추가한다. 추가 실모델 추론·다운로드·Drive·유료 API·평가기는 보류한다. dev 검증 기록과 정상 push로 마친다.
