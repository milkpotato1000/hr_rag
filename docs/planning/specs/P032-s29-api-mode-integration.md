# P032 S29 · 선택 API 모드의 설치본 통합 검증

dev 71d2009 기준 S14는 OpenAI Chat과 Anthropic Messages의 설정·미리보기를, S5는 고정 문맥에서 실제 로컬 답변과 API 미리보기 비교를 확인했다. 사용자 계정 없이 두 API 형식의 전송부터 답변·인용 저장까지 설치 제품의 정상 진입점을 시험한다.

1. 기본 합성 규정집의 한 질문·고정 BM25 문맥으로 설치 CLI에서 두 provider 프로필을 준비한다. HTTPS loopback에 소유한 시험 서버만 사용한다. 임시 신뢰 인증서는 시험 프로세스에만 지정하고 기존 TLS 검증과 기본 endpoint 정책을 유지한다. 테스트 전용 환경변수의 더미 키만 사용하고 인증 값은 산출물에 저장하지 않는다.
2. 각 provider에서 미리보기 전송 0회, 명시 실행 1회, 저장 재열기 추가 전송 0회를 확인한다. 시험 서버는 실제 요청에서 역할별 메시지·질문과 문맥·요청 모델·인증 방식이 예상과 같은지 대조하고 전달된 실제 청크 ID를 인용하는 고정 응답을 반환한다. 두 형식 모두 답변·원문·페이지·사용량이 설치 CLI 결과와 저장 기록에 연결되는지 확인한다. 같은 입력에서 두 결과를 기존 비교 명령으로 열고 호환되는 저장 로컬 결과가 있다면 재사용한다.
3. 키 누락 및 인증 거부를 각각 검사하고, 실패가 답변으로 표시되거나 자동 재시도되는지 확인한다. 모델 키 본문, 인증 헤더, 시험용 개인 키는 커밋하지 않는다. 실 provider·유료 API·Ollama 생성·Drive·자동 평가기 호출은 0회다.
4. 기존 설치 안내에 사용자가 준비할 모델명·키 환경변수·미리보기·명시 실행·결과 확인 방법을 연결한다. 실제 공급자의 모델 접근권·요금·답변 품질은 미측정으로 구분한다. 기존 제품 경로를 재사용하고 재현된 결함만 수정한다. 검증 기록과 설치본 회귀 결과를 dev에 푸시한다.
