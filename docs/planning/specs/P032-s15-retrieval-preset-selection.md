# P032 S15 · 설치 실습에서 검색 구성 선택하기

## 준비 검토

dev f690f74는 로컬/API 생성 프로필을 명령으로 준비한다. HANDBOOK의 Dense·Hybrid 비교는 학습자가 Python으로 템플릿을 읽고 임베딩 경로·검색 방식을 써야 한다. 통합 실행과 학습 UI의 프로필 등록도 각각 조립한다. 기존 모델 준비·검증 및 통합 실행기를 사용해 두 단계 사이를 연결한다.

## 구현 및 검증 기준

1. 독립 설치 실습 폴더에서 코딩 도구와 사용자가 비대화식 명령으로 준비된 생성 프로필, 청킹 설정, BM25·Dense·Hybrid, 지원 공개 임베딩 프로필, 선택 리랭커와 K·후보 수·문맥 예산을 지정한다. 모델 준비 명령이 출력한 프로필을 그대로 참조한다. JSON 수작업이나 Python 스니펫 없이 재사용 가능한 설정과 실제 파일을 가리키는 미리보기·학습 UI 명령을 얻는다. 입력 프로필과 기존 출력 폴더를 보존한다.
2. BM25 단독은 임베딩 없이, 리랭커 끔은 리랭커 프로필 없이 구성한다. Dense·Hybrid에는 선택한 임베딩, 리랭커 켬에는 선택한 리랭커와 revision을 반영한다. 역할 오류·준비 누락·서로 불가능한 K 및 예산은 기존 검증기를 통해 설명하고 실행 가능한 설정으로 표시하지 않는다. 기본 설정 시 모델 다운로드·추론·키 조회·문서 전송은 0회다.
3. S14에서 생성한 프로필과 배포 규정집을 사용해 새 wheel에서 BM25·리랭커 끔, Dense·E5, Hybrid·BGE-M3, 리랭커 끔/각 지원 모델 켬을 검증한다. 기존 준비 파일을 활용하고 fixture 사용 여부를 기록한다. 한 변수만 바꿀 때 다른 값이 보존되는지, 출력 명령으로 여는 CLI 미리보기와 UI의 실제 선택값·등록 상태가 일치하는지 확인한다. 사전선택과 선택지 등록을 구분해 안내한다. 잘못된 역할, 공백 있는 경로, 기존 출력, 이전 직접 작성 설정 회귀를 확인한다.
4. 학습자가 같은 질문에서 임베딩만 또는 리랭커만 바꾸는 명령과 관찰할 항목을 설치 안내에 넣는다. 기존 S4/S12/S13 결과와 연결한다. 실제 Qwen 호출 추가·Drive·평가기·유료 API·모델 다운로드는 보류한다. 독립 설치 검증과 dev 정상 push까지 진행한다.
