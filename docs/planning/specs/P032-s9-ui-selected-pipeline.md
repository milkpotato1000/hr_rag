# P032 S9 · 학습 화면에서 선택한 RAG 실행하기

## 준비 검토

S8 dev fa28725는 설치 CLI의 pipeline과 pipeline-replay로 현재 규정집에서 답변과 인용까지 검증했다. 학습 UI는 개별 단계와 저장 답변 비교를 제공하지만 같은 통합 실행 진입점은 아직 CLI에 있다. 기존 실행 엔진과 UI의 작업·설정 등록 체계를 연결한다.

## 범위와 완료 기준

1. 설치본 학습 UI에서 로컬 PDF 소스, 질문, 등록된 생성 프로필(로컬 또는 API), 청킹 방식과 설정, Sparse(BM25)·Dense·Hybrid 및 임베딩, 리랭커 끔/켬과 프로필을 선택한다. 기존 등록 설정과 실행 작업을 재사용한다. 별도 실험 메뉴에는 상세 비교를 유지한다. 기본 화면은 선택 결과로 미리보기 → 명시 실행 → 답변·인용 열기까지 연결한다.
2. CLI와 같은 pipeline.run/replay를 통해 유효 설정, 목적지, 예정 호출량, 실제 단계별 상태·오류·결과를 표시한다. 모델 호출이 필요한 조합의 실행은 해당 서버 권한과 사용자의 실행 선택이 모두 있을 때만 한다. BM25와 규칙 청킹은 불필요한 모델 권한을 요구하지 않는다. 중복 클릭·실행 중 새로고침은 기존 작업 기록으로 이어지고 후속 중복 호출이 발생하지 않는다. UI가 받는 설정과 결과는 기존 workspace 등록 ID로 제한한다.
3. 최종 답변에서 인용을 선택하면 장·절·조항, PDF 페이지, 인용 원문을 읽을 수 있어야 한다. S8의 설치 CLI 결과를 같은 workspace로 가져와 다시 열고 재추론 0회를 확인한다. 실패·보류·미리보기에서 실제 답변이 있는 것처럼 표시하지 않는다.
4. 독립 wheel 설치본과 실제 브라우저로 현재 규정집의 미리보기, 선택 변경, 실험 메뉴 이동, S8 저장 결과 재열기를 관찰한다. 모델 없는 테스트 어댑터로 실행 클릭부터 완료·실패와 권한 누락·중복 요청까지 검증한다. 실제/시험 어댑터/저장 재생을 분명히 구분한다. 이번 단계에서는 S8의 실측을 재사용하고 추가 모델·API 호출·다운로드·Drive 연결·평가기는 보류한다.
5. 실습 안내에 serve 시작 명령, 선택 순서, 인용 위치를 기록한다. CLI와 UI의 동일 설정 미리보기 대조, 이전 단계별 UI 회귀, 설치 리소스 검사, 학습 보고서·dev 정상 push까지 확인한다.
