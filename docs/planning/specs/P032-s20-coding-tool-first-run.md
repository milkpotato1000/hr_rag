# P032 S20 · Codex와 Claude Code에서 첫 실습 시작

## 준비 검토

dev c507431의 설치 안내는 dev 소스를 받은 뒤 build venv·wheel·실습 venv·init을 순서대로 만들도록 한다. START_HERE의 도구별 요청은 설치 후의 preview부터 시작한다. 새 사용자가 공개 소스에서 첫 PDF 검색까지 한 요청으로 따라갈 경로를 제공한다. 점검한 호스트에서 Codex CLI와 Claude Code는 각각 version/help가 실행됐다. 이는 두 도구의 실제 모델 세션이나 계정 인증 검증이 아니다.

## 범위와 완료 기준

1. 공개 dev 소스의 README 첫 화면에서 두 도구에 그대로 전달할 한국어 요청을 제공한다. 어느 폴더에서 시작해 무엇을 실행하고 결과를 어디서 읽는지 명시한다. 두 도구는 같은 결정적 설치·실습 절차를 호출한다. 설치 전 소스 SHA, 필요한 Python과 의존성, 작업 폴더를 확인하고 기존 빌드·실습 폴더 및 사용자 파일을 보존한다.
2. 기존 wheel 빌드·hash lock·init·PDF reader·BM25 검색 명령을 재사용해 초심자가 수작업으로 경로를 연결하지 않아도 배포 규정집의 첫 질문을 재현할 수 있게 한다. 빌드/설치와 문서 검색의 결과를 구분하고, 중간 실패 시 어느 단계부터 복구할지 표시한다. 반복 실행 시 이전 결과를 덮어쓰지 않는다.
3. 새 독립 폴더에서 문서에 안내한 정상 진입점을 실행해 wheel 설치 출처, 규정집 원본 해시, 첫 질문의 전달 청크·쪽수·BD-03의 신청 기한을 확인한다. 소유 환경 안의 의존성만 준비하고 설치 가능한 로컬 wheel cache가 있으면 사용할 수 있다. 검색된 문장과 모델 생성 답변을 구분한다. 공백 있는 경로·기존 대상·설치 실패 경로를 확인한다.
4. 같은 설치 결과에서 사용자 요청에 따라 로컬 Qwen 실제 생성, API 설정, 청킹·검색·리랭커 실험으로 이어지는 명령을 S14~S16 문서와 연결한다. 이번 단계에서는 코딩 도구 버전/도움말 확인과 공통 절차의 실제 실행을 각각 보고한다. 외부 코딩 에이전트 세션·유료 API·Drive·평가기·모델 다운로드·추가 추론은 실행하지 않는다. 기존 수동 설치 경로 검증, 실행 기록, dev 정상 push까지 진행한다.
