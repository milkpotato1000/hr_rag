# P032 S25 · 첫 설치에서 규정집 실답변까지

## 준비 검토

dev 750df24의 첫 설치 스크립트는 설치·규정집 snapshot·BM25 인덱스와 첫 검색 근거를 이미 만든다. 공개 README의 후속 명령은 새 모델 및 검색 설정을 만드는 데서 끝난다. 설치한 사용자가 준비된 Ollama로 같은 질문의 답과 인용을 바로 얻을 수 있도록 두 흐름을 연결한다.

## 개발 및 검증 범위

1. README와 설치 실습의 첫 진입점에 “기존 로컬 Qwen으로 첫 답변” 경로를 제공한다. 첫 검색을 마친 작업 폴더에서 복사해 실행할 수 있는 짧은 명령 또는 기존 CLI로 구성한 실행기를 쓴다. 같은 질문·PDF와 호환되는 기존 snapshot·BM25 인덱스를 재사용한다. 재설치나 새 인덱스가 필요한지 실제 호환 검사를 근거로 결정한다.
2. 기본 첫 검색은 생성 0회로 유지한다. 사용자가 로컬 생성 실행을 선택하면 준비된 모델과 기존 실습 프로필을 확인한 후 한 번 생성한다. 성공 시 답변, 인용의 PDF 페이지·조항을 확인할 수 있는 원문, 결과 위치를 쉽게 찾도록 한다. Ollama 미실행 또는 모델 없음은 필요한 조치가 드러나는 결과로 처리하고 기존 실습 산출물을 보존한다.
3. 새 사용자가 보게 될 README의 명령 그대로 first_handbook 결과에서 시작하여 설치 환경에서 로컬 Qwen 4B 한 건을 검증한다. 통제된 실험 한도와 자원 점검을 유지한다. 생성 결과·인용 구간과 규정집 BD-03 원문을 대조하고 최초 검색 재사용 여부를 기록한다. 이미 존재하는 출력, 모델 미준비, 기본 검색 경로도 검증한다. 실제 코딩 도구 세션·Drive·유료 API·평가기는 실행하지 않는다.
4. 코딩 도구에 붙여넣을 공통 요청 예시, 선택 실행 단계, 결과를 읽는 방법을 첫 진입점에 연결한다. 검증 기록과 패키지 변경을 dev에 푸시한다.
