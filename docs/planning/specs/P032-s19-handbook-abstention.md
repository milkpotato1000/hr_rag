# P032 S19 · 규정집에 월 지원 한도가 없는 질문

## 준비 근거

dev 2aeee85의 고정·재귀 청킹과 로컬 Qwen 4B 경로는 승인권자처럼 근거가 있는 단일 질문에서 답변했다. 승인된 gt09는 “재택근무 전기요금의 월 지원 한도는 얼마인가요?”다. 사람 검토 기준에는 금액 미명시와 제도 부재가 구분되어 있다. [승인 검토 기준](../reviews/P013-human-review.md)과 현재 합성 규정집을 읽기 전용으로 사용한다.

## 실행 및 검증

1. 배포 PDF와 승인 검토의 문서 버전·해시를 확인한다. S11의 고정 400/80, BM25 후보 20·최종 5·예산 4000, 리랭커 끔, 동일한 로컬 모델 digest와 생성 옵션을 사용한다. 독립 설치본의 일반 pipeline 경로에서 gt09를 그대로 질문한다. 승인 정답·기대 상태나 추가 보류 지시는 모델에 전달하지 않는다.
2. 전달 예정 청크 및 실제 전송 청크의 순위·페이지·본문을 보관한다. 관련 조항과 다른 복지 항목의 금액을 구분해 어느 근거가 실제 문맥에 있었는지 확인한다. 전송할 청크가 없으면 코드의 무호출 보류를 별도 기록한다. 문맥이 있는 경우 S11의 서버 소유·자원·시간·정리 조건 아래 모델 실제 생성 최대 1회, 자동 재시도 0회.
3. 저장된 기술 상태와 실제 답변 전문·인용을 독립적으로 기록한다. 승인 기준에 따라 금액을 만들었는지, 미지급 또는 제도 부재로 단정했는지, 한도를 문서에서 확인할 수 없다는 뜻을 전달했는지 대조한다. 모델 보류는 빈 인용 규약도 검사한다. answered로 반환한 적절한 문구, 모델의 abstained, 코드의 무호출 보류, 잘림·스키마 오류 등은 서로 다른 결과다. 빈 정답 클레임으로 점수를 생성하지 않는다.
4. 기존 근거가 있는 S11 답변과 이 결과를 학습 문서에 연결한다. 한 질문의 관찰임을 표시한다. 재생 호출 0회·입력 보존·소유 서버 정리를 확인하고 검증 자료를 dev에 정상 push한다. 다른 질문, 자동 평가기·Drive·유료 API·다운로드·청킹 실험은 보류한다.
