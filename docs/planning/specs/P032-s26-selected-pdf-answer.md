# P032 S26 · 내가 선택한 PDF와 질문으로 첫 실답변 얻기

## 준비 검토

dev db64fc8에서 first-answer는 기본 규정집의 첫 검색을 재사용한다. S16은 사용자가 지정한 PDF 경로와 질문이 설치 CLI와 UI에 적용되고 원문의 근거가 검색되는 단계까지 검증했다. 선택한 PDF에서 실제 답변을 생성하고 인용이 그 파일을 가리키는지까지 기존 통합 경로로 검증한다.

## 실행 및 검증

1. 독립 설치 환경에서 S16의 합성 교육 휴가 PDF와 동일 질문(문서 식별자·버전)을 사용자가 입력하는 로컬 파일·질문의 예로 사용한다. 기존 generation-setup, pipeline-setup, pipeline 명령으로 BM25·리랭커 끔·기존 로컬 Qwen 4B를 구성한다. 실습 안내에 복사 가능한 미리보기와 선택 실행 명령을 나란히 두고, 사용자마다 다른 출력 경로는 실제 생성된 설정을 이용한다.
2. 미리보기에서 선택한 문서 지문, 질문, 모델 설정을 확인한다. 실행은 기존 메모리·자원 점검 뒤 1회로 제한한다. 실제 답변을 식별자 HR-V3-TRAINING 및 버전 3과 각각 대조한다. 인용한 문서 ID·페이지·원문이 선택 PDF에서 왔는지 확인하고 기본 규정집으로 대체되지 않았음을 검증한다. 실패·부분 답변도 그대로 기록한다.
3. 저장 결과를 다시 열어 같은 질문·근거·답변인지 확인한다. 기존 첫 규정집 경로의 호환성과 입력 PDF 원본 보존을 검증한다. 이미 지원되는 기능을 재사용하고 진입점에 필요한 안내 또는 재현된 결함만 수정한다. 검증에는 합성 자료만 사용하며 외부 전송, Drive·상용 API·평가기 및 새 모델 다운로드는 범위 밖이다. 설치 가이드와 결과를 dev에 푸시한다.
