# P032 S11 · 설치한 학습 화면에서 새 질문에 실제 답변 받기

## 준비 검토

dev 185c919의 독립 설치본은 규정집과 안내서를 포함한다. S8에서 CLI가 로컬 4B로 신청 기한에 답했고, S9의 브라우저에서는 저장된 그 답변과 시험 어댑터의 신규 작업을 확인했다. S10은 PDF 검색까지만 실행했다. 학습자가 설치 직후 화면에서 질문을 바꿔 실제 답변을 받는 경로를 검증한다.

## 실행 및 판정

1. 새 독립 실습 폴더에서 배포 PDF와 기존 로컬 Qwen 4B 프로필을 사용한다. 일반 사용자용 serve와 브라우저를 통해 규칙 청킹·BM25·리랭커 끔을 선택한다. 질문은 “생일 특별휴가를 신청하면 누구의 승인을 받아야 하나요?”로 고정한다. 실행 전 미리보기와 최종 입력에서 질문이 바뀌었는지, 검색 근거에 BD-03의 승인 문장이 포함되는지 기록한다.
2. S8의 모델 식별·소유 서버·자원·시간 제한·종료 제어를 재사용한다. 실제 브라우저의 실행 버튼으로 생성 최대 1회, 자동 재시도 0회. 작업 ID, 제출한 질문, 실제 생성 상태와 답변, 시간, 인용 청크·PDF 페이지·원문 및 저장 결과 재열기를 대조한다. 신청 기한 대신 승인권자인 ‘팀장’을 답했는지 사람이 원문과 대조할 수 있도록 기록한다.
3. UI 동작, 검색, 생성, 인용의 결과를 구분한다. 근거 누락, 모델 오답, abstained, 시간 초과는 관찰한 상태대로 보고한다. 이전 답변 재생이나 시험 어댑터로 실호출 성공을 대신하지 않는다. 모델을 부르기 전 고칠 수 있는 UI 연결 결함은 수정하고 회귀 검증한다. 실험 후 소유 서버와 모델을 정리하고 dev 기록을 게시한다.
4. Drive·평가기·유료 API·새 모델 다운로드는 보류한다. 이 한 질문의 결과로 모델 전체 품질을 일반화하지 않는다.
