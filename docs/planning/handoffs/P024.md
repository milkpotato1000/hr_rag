# P024 공개 모델 기본 학습 자료 인계

대상: 기존 HR RAG dev. 권한과 준비 근거는 [P024 준비 검토](../reviews/P024-readiness.md), 범위는 [P024](../plans/P024.md), 최종 목표는 [RAG 패키지 로드맵](../rag-package-roadmap.md).

이 문서를 포함한 READY 커밋의 전체 SHA를 실제 메시지와 handoff 이벤트에 기록한다. 안전하게 통합하고 정확 SHA를 adopt한 뒤 adoption을 커밋하고 P024만 진행한다. 제품 학습 문서/비실행 JSON 예시/진입 링크와 검증 기록을 dev에 작성한다. 정상 non-force personal/dev push까지 기존 권한을 따른다. main 승격은 제외다.

P013은 보류한다. 이번 정정은 DRAFT/history 충돌을 없애기 위한 준비 완료 보존이다. dev의 차단 실행 상태, C1/기존 실행 로그, 성공1건, 실패, 승인 GT, 미소비 recovery grant를 보존한다. 이번 adoption이 모델 재개·Ollama 서버 시작·실호출·다운로드를 허용하지 않는다. 원래 실패 이력을 없애서 merge/adoption을 통과시키지 않는다.

완료 증거: P024 C1~C4와 docs/verification/p024/에 JSON 파싱·링크·인용 명령·지원 상태·비밀값 부재·guard 체크 결과. 실제 모델/API/브라우저 확인을 하지 않았으면 그 사실을 구분한다. 제품 adapter 구현/범용 UI/유료 호출은 이번 범위가 아니다. 후속 범위는 별도 계획을 기다린다.

plan은 dev의 실제 응답/커밋을 관찰해 수신·adoption·완료를 따로 기록한다. 역방향 메시지를 요청하지 않는다.
