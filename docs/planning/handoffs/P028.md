# P028 설치 패키지 후속 인계

이 READY full SHA는 후속 큐다. 현재 P027은 중단하지 않는다. P027 C1~C3 완료·검증/커밋/personal-dev 반영 후 안전한 경계에서 통합·정확 adopt·커밋·guard/큐 확인하고 P028만 착수한다. 완료 전에는 이 카드 구현/기존 작업 혼합을 하지 않는다.

[P028](../plans/P028.md), [계약](../specs/P028-installable-package-contract.md), [준비 검토](../reviews/P028-readiness.md)를 읽는다. 실제 wheel/sdist·명시 file allowlist·console CLI·init/doctor·설치 전용 한국어 가이드와 Claude Code/Codex 공통 실습이 범위다. 두 도구의 실제 UI 검증을 했다고 주장하지 않는다. 기존 API/schema·HR stages/evaluator를 보존한다. placeholder sample이 실제 API에 전송되지 않도록 invoke의 configuration_required preflight를 포함한다.

P027 final lock을 재사용한다. build1.6.1/setuptools84.2.1 후보와 transitive lock/새 격리 venv 검증은 허용하되 기존 환경/global 설치·모델 다운로드·서버 시작·실제 API/Drive/OAuth·개인키 접근은 제외한다. P013 보류·grant 미소비·기존 증거를 유지하고 Hybrid/리랭커 미결 순서도 유지한다. PyPI publish/라이선스 변경/main 승격은 제외다.

개발 source 없는 cwd/PYTHONPATH unset에서 설치물만으로 실습하고 core-only/PDF/Drive extras를 분리 검증한다. C1~C3 증거/실행 로그와 normal personal/dev push를 완료한다. 새 범위는 intake, 범위 내 오류는 수정·재검증한다. 역방향 메시지는 요구하지 않는다.
