검토일: 2026-10-22 Asia/Seoul
상태: 준비 완료

## 요청과 현재 상태

사용자는 Naive RAG를 E2E로 완성하고, 구현 자체는 Codex가 끝까지 맡으며 본인은 의미 이해·평가·최적화 실험을 중심으로 학습하기를 요청했다. 추가로 P문서별로 쪼개 차근차근 구현하도록 지시했다.

현재 큐는 P001 완료 6/6, P002 완료 8/8이다. dev a0ce4da55f9a309a50db7420fc400543d8452bb9에 BM25·37개 테스트·단독 실행·원본 보존의 증거가 커밋돼 있다. 이번 카드는 검색 기반까지이며 P004 생성, P005 화면·E2E·학습 가이드는 선행 결과를 검토한 뒤 개별 계약으로 준비한다. 모두 `1. Naive RAG/` 안의 작업이다.

## 준비 판단

- 실기기는 Apple arm64, 메모리16GiB, 여유 디스크 약324GiB다. Ollama 실행 파일·11434 서비스가 없고 uv가 있다. 현재 기본Python은3.9.6이다.
- 공식 Ollama v0.40.8의 macOS tar URL·SHA-256을 GitHub release API로 확인했다. qdrant-client1.19.1의 Python>=3.10 요구에 맞춰 격리된3.12환경을 선택한다.
- 임베딩은 BGE-M3 Dense로 정했다. 최초 pull의 실제 digest·양자화·차원·라이선스를 lock에 기록하고 색인과 함께 검증한다.
- 사용자 E2E 구현 요청 안에서 필요한 로컬 런타임·공개모델·격리환경 다운로드와 loopback 서비스 실행을 명시적으로 범위에 넣었다. 유료API·GPU임대·원격연동·배포나 전역서비스 설치는 포함하지 않는다.
- corpus·질문·qrels·기존 완료조건은 보존한다. Dense와 BM25는 같은 입력과평가기에서 비교하되 원점수·검색결과 존재를 근거충분성으로 취급하지 않는다.
- 독립 cosine 기대값, 영속색인재open, stale색인·HTTP/벡터오류·출력보전, 실15청크/14질문 비교를 완료기준으로 정했다. 모의모델 테스트만으로 실제 실행 완료를 주장하지 않는다.
- P003은 생성·답변품질을 다루지 않는다. 검색기완료와 Naive RAG E2E완료를 분리한다.

구체 계약과 기술출처는 [P003](../plans/P003.md)에 기록했다. 네트워크나 런타임 실행이 막히면 실제오류를 남기고 의미있는 우회·진단 후 차단을 보고하며 가짜 모델로 완료처리하지 않는다.
