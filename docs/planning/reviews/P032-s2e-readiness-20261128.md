## 근거

S2d 실제 결과는 provider.status=truncated,finish_reason=length,input1778/output1024,elapsed87473.344ms,identity 전후verified,outcome_unknown=false,answer=null이다. 전체721파일 hash를 [중단 감사](p032-s2d-halt-audit.json)에 저장했다. 서버 종료 증거는 소유 PID74620의 unload/normal 관찰 후종료를 기록한다. 부모 ledger의 server_completion=unknown은 원형 보존하며 별도관측의 HTTP응답/종료를 구분한다. 다음 실행에서 종료된 부모를 재사용하지 않는다.

[Qwen 공식 카드](https://huggingface.co/Qwen/Qwen3-4B-Thinking-2507)는 이 모델의 Thinking 전용, 긴 추론 출력,temperature0.6을 명시한다. [Ollama 공식 문서](https://docs.ollama.com/capabilities/thinking)는 think 제어와 분리된 message.thinking/content를 설명한다. [chat API](https://docs.ollama.com/api/chat)의 format/keep_alive/usage도 확인했다. 원문 확인일2026-11-28. 현 서버 버전 동작을 최신문서만으로 보증하지 않는다.

제품 config.py의 허용 필드, llm_setup의 spec 필드 복사, core.preview의 false고정 및 core 응답의 nonempty thinking거부를 읽었다. 명시 true profile이 없으므로 기존모델 선택을 유지하면서 final-only 응답을 검증할 구현이 필요하다. 단순 length 결과를 thinking 소진의 증명으로 사용하지 않는다.
