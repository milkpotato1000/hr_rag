## 목적과 범위

원문에 맞는 사실인지와 질문에 반드시 필요한 사실인지를 분리한다. 완료된 P022의 57개 원자 후보를 보존하며 질문별 필수38개·보충19개와 분류 근거를 새 run004에서 확인한다. 보충 정보 누락 때문에 간결한 정답이 감점되거나, 보충 정보의 오류가 핵심 점수에 가려지는 것을 방지하는 정책을 P013에 인계한다.

의미 기준은 [전수 분류 JSON](../reviews/p023/run003-scope-audit.json), [검토 설명](../reviews/P023-scope-review.md), [실행 계약](../specs/P023-scoped-review-contract.md), [채점 정책](../specs/P023-scoring-policy.md)이다. 순서는 P022 완료 → P023 분류 검토본 → 새 정답 버전 승인/준비 게이트 → P013이다. P013은 DRAFT를 유지한다.

- 신규 모델 실행·평가기 구현은 없다. 정책 및 고정 기대값을 읽기 화면에 제시하고 P013 인계 자료로 전달한다. 기존 run001~003/모델 이력·source-v4/P007 자료는 불변이다.

- 요청 원격은 기존 personal plan/dev. main 승격, 다른 프로젝트/하네스, 서버·모델 변경은 범위 밖이다.
