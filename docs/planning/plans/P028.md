## 목적

저장소 루트·기존 venv에 의존하는 P025~P027을 설치 가능한 Python wheel/sdist와 독립 실습 프로젝트로 제공한다. 사용자가 패키지를 설치한 뒤 다른 폴더에서 샘플 문서→청킹→검색→생성 preview를 재현하고 본인 모델/Drive 설정으로 전환할 수 있게 한다. 이 카드는 완성된 UI나 실모델 성능 검증을 대신하지 않는다.

## 범위

[패키징 상세 계약](../specs/P028-installable-package-contract.md)을 따른다. pyproject/package data/console command, init/doctor, 한국어 설치·복구·두 코딩 도구 요청 가이드, 새 venv의 wheel-only 및 sdist 재빌드 시험이 범위다. 실제 모델/API/개인 계정/문서 접근, PyPI publish, main 승격, 글로벌 설치는 제외한다. P013 보류와 Hybrid/리랭커의 기존 선행을 유지한다.

P027 현재 SDK 설치/import 증거와 P025/P026 실제 CLI·storage·설정 경로를 읽어 [준비 검토](../reviews/P028-readiness.md)를 완료했다. P027 최종 완료와 lock은 착수 전에 다시 확인한다. 선행 완료가 되지 않으면 실행하지 않는다. API는 선택 LLM 교체이며 임베딩/리랭커 공개 모델 기본 방침을 계승한다. 패키지 설치를 특정 모델 실행 성공으로 표시하지 않는다.

## 검증 계획

개발 저장소가 sys.path/PYTHONPATH/cwd에 없는 새 환경에서 wheel 설치·공통 CLI·init·TXT/MD snapshot/build/ask-preview/compare, PDF extra와 Drive SDK extra를 분리 시험한다. 테스트 fixture가 설치물의 production 응답으로 섞이지 않는지 wheel/sdist allowlist를 검사한다. 플랫폼/Python 버전의 실제 검사 범위를 기록한다.
