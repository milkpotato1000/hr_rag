# P027 — Google Drive 문서 링크 수집과 버전 snapshot 연결

> 준비: 준비 완료
> 실행: 미착수
> 우선순위: 8
> 선행: P026
> 승인 근거: 사용자의 문서 저장소 Google Drive 가정 및 2026-11-27 지원 웹하드 문서 링크 입력형 패키지 목표. 2026-11-27 준비 검토 완료. 실제 계정/모델 실행은 제외.

## 목적

사용자가 권한을 가진 Google Drive 문서 링크를 넣어 P026 일반 문서 snapshot에 연결한다. 기존 Drive fixture를 실제 API 연결로 오인시키지 않으며 다른 웹하드는 동일 connector 계약의 후속 확장이다.

## 확정 계약과 준비 검토

[Drive connector 계약 v1](../specs/P027-drive-connector-contract.md), [준비 검토](../reviews/P027-readiness.md), [공식 자료 조사](../reviews/P027-source-research.md)를 따른다. P026 완료 dev/personal-dev 0252ec1731431c67172f7692b14fed7ec763821f를 확인했다.

## 범위

단일 Google Drive PDF/TXT/MD 또는 Google Docs의 PDF export를 실제 REST 코드로 수집해 P026 snapshot에 연결한다. preview 기본, 명시 execute만 다운로드하며 OAuth helper와 access-token-env를 지원한다. Google OAuth SDK는 격리 환경에서 설치/lock/검증하며 기존 모델 환경은 변경하지 않는다. 실제 Google 로그인/사용자 파일 접근은 이번 시험에서 수행하지 않는다.

정확 링크·MIME·인증/credential 저장·metadata 전후 버전 확인·checksum·한도·실패·secret 비노출·불변 artifact와 provenance를 계약으로 고정했다. 폴더/shortcut/shared-drive/다른 Workspace 앱/자동 sync는 제외한다. 변경은 명시 재수집/rebuild이며 원자적 revision 다운로드라고 주장하지 않는다. 새 버전을 기존 index와 섞지 않는다. 실제 API 코드를 fake production 응답으로 대체하지 않는다.

P013 hold·실행 이력/GT·grant와 기존 단계/P025/P026 동작은 보존한다. P010/P020 순서 변경에 대한 사람의 답변은 대기 중이며 이 독립 connector 작업으로 해당 선행을 해제하지 않는다.

## 검증 계획

정상/권한거부/만료 token/resource key/개정 경쟁/잘못된 링크/허용크기/부분다운로드 등 transport fixture와 P026 snapshot 연결을 검증한다. 실제 Drive E2E는 지정한 파일/계정 권한으로 따로 확인하고 fixture 성공과 구분한다.
