> 승인 근거: 사용자 최종 goal의 누구나 설치·모델 선택·비교 가능한 RAG 패키지. 구현된 선택 기능을 파일·설정 준비까지 연결한다. 준비 검토 후 정확 READY 채택 범위에서 개발한다.

## 목적과 확인한 차이

P010/P020는 실제 SDK adapter를 제공하지만 사용자가 HF revision·파일별 hash·자체 완결 export 디렉터리를 직접 마련해야 한다. P028 고정 설치 안내만 따라가면 최신 기능이 들어 있지 않은 과거 빌드로 이동한다. 모델 선택과 실행 준비 사이의 수작업을 줄이고 실제 지원 상태를 구분한다.

[모델 준비 설계](../specs/P031-model-preparation-design.md)를 기준으로 catalog·준비 preview·명시 다운로드/로컬 import·검증된 profile 출력, LLM local/API 설정 안내와 최신 설치 실습을 검토한다. 기존 runtime의 pinned manifest·원문/GT·실행 분리 정책을 유지한다. 모델을 자동으로 호출하거나 평가기 실험을 재개하는 카드가 아니다.

## 확정한 범위와 검증

- P030 완료 aa3010f9f1709c3152e0bd8ed570fc5516b92a93의 config v2/registry/resource와 최종 검증을 기반으로 한다.
- 네 HF 모델의 고정 revision·파일 recipe·hash와 구조를 조사 자료로 고정했다. BGE-M3 Dense의 tensor-only 변환과 출처·값 보존을 별도 검증한다.
- 명시적인 준비·다운로드/로컬 import·변환·설정 작성과 기존 추론을 분리한다. 기본 preview는 네트워크·키·모델 실행0이다.
- LLM local/API 설정 생성, 읽기 전용 local inspect, 역할별 doctor와 UI 등록·설치 학습 흐름을 연결한다.
- 개발 검증은 실제 tiny SDK와 fake metadata/file/provider transport로 수행한다. 실제 사전학습 가중치 다운로드/로드·LLM/API·Drive/OAuth/개인키 호출0이며 P013/P014 보류·P029 C4 미완료·기존 GT/실패/grant를 유지한다.
- [준비 검토](../reviews/P031-readiness-20261128.md)와 [실행 계약](../specs/P031-model-preparation-contract.md)이 우선한다. 범위 밖 결정은 intake로 남기고 계약을 완화하지 않는다.
