# P031 — 모델 준비와 최신 설치 실습 연결

> 준비: 초안
> 실행: 미착수
> 우선순위: 23
> 선행: P030
> 승인 근거: 사용자 최종 goal의 누구나 설치·모델 선택·비교 가능한 RAG 패키지. 구현된 선택 기능을 실제 모델 준비까지 연결하는 후속 초안이며 실행 인계는 아니다.

## 목적과 확인한 차이

P010/P020는 실제 SDK adapter를 제공하지만 사용자가 HF revision·파일별 hash·자체 완결 export 디렉터리를 직접 마련해야 한다. P028 고정 설치 안내만 따라가면 최신 기능이 들어 있지 않은 과거 빌드로 이동한다. 모델 선택과 실행 준비 사이의 수작업을 줄이고 실제 지원 상태를 구분한다.

[모델 준비 설계](../specs/P031-model-preparation-design.md)를 기준으로 catalog·준비 preview·명시 다운로드/로컬 import·검증된 profile 출력, LLM local/API 설정 안내와 최신 설치 실습을 검토한다. 기존 runtime의 pinned manifest·원문/GT·실행 분리 정책을 유지한다. 모델을 자동으로 호출하거나 평가기 실험을 재개하는 카드가 아니다.

## 준비 전에 확정할 사항

- P030 최종 config/registry/resource manifest와 샘플의 실제 기능을 대조한다.
- 네 embedding/reranker 후보의 정확 revision·필수 파일·상한과 safetensors 가용성을 확인한다. BGE-M3 변환을 지원할 경우 입력 신뢰·tensor-only 변환·출력 provenance·독립 검증을 확정한다. 파일 형식이 맞지 않는 모델을 준비 완료로 표시하지 않는다.
- 다운로드 SDK/의존성, preview의 네트워크 여부, 명시 실행·부분 실패·중단/재시작·덮어쓰기 방지와 파일 manifest 생성을 확정한다.
- 로컬 LLM 목록/identity 확인과 API 설정 작성은 별도 작업이다. Ollama 자동 시작/모델 pull/평가 grant 소비 없이 선택된 설정을 구성하도록 경계를 확정한다.
- 최종 개발 검증과 실제 사전학습 모델·문서 E2E 검증을 구분한다. 실모델 다운로드/추론의 구체적인 실행 계약은 READY 전에 정한다.
