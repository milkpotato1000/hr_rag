P007의 원문 재작성을 독립 선행 작업으로 분리한다. 실제 회사 규정처럼 읽히는 **가상** HR 원문을 먼저 만들고 PDF 화면→추출 텍스트까지 검증한다. 새 원문을 고정한 뒤 P007에서 청킹/검색을 비교하고 P013에서 답변 평가기를 만든다. 문서 품질과 청킹/검색기 개선 효과를 한 변경으로 섞지 않는다.

## 원문 작성 계약

1. 기존 주제인 생일 특별휴가·연차·재택근무·복지·교육휴가·출장의 편집 원문 Markdown 6개와 각각 대응하는 텍스트 레이어 PDF 6개를 작성한다. 수집 대표 입력은 PDF만 선택해 Markdown과 중복 색인되지 않게 한다.
2. 제목, 문서 식별자/버전, 적용 대상, 사용/지급 기준, 예외, 신청/승인 절차를 주제에 맞게 배치한다. 없는 규정의 항목을 채우려고 새 정책을 만들지 않는다. 시행일이 원래 없으면 unknown/null로 기록하고 실제 시행일·결재자·회사 직인·승인을 꾸며내지 않는다.
3. 기존 정책의 숫자·단위·대상·부정·예외·기한·승인 주체를 보존한다. 기존15청크 및 source-v2의 모든 규정 주장→새 문서/조항 대응표를 작성한다. 기존15 facts만으로 전체 보존을 단정하지 않는다. 출처 간 실제 정책 충돌은 임의 해결하지 않고 plan 피드백으로 남긴다.
4. “답변을 작성할 때는”, 평가 질문별 해설, 청크·검색 방법 안내, 페이지를 넘는 읽기 연습 등은 검색 원문에서 분리해 `data/source-v3/authoring-notes.md`에 보존한다. 독립 규정 문서로 먼저 작성하며 정답 청크/질문 순서대로 조립하지 않는다. 안내·노트·정답 파일은 수집 manifest에서 제외한다.
5. 가상 규정 안내는 문서 앞부분에 명확히 표시한다. 제목/가상 안내를 매 청크에 인위적으로 붙이지 않는다. 본문에 실제로 있는 안내와 페이지 번호는 추출 결과에 보존하고 메타데이터와 구별한다.
6. 읽을 수 있는 한글 글꼴, 자연스러운 조항·문단/목록, 페이지 번호·여백을 사용한다. 분량/청크 수를 늘리려고 문장을 반복하거나 새 조건을 추가하지 않는다. 페이지 수 목표를 강제하지 않으며 기존 다중 페이지 경계 fixture는 보존한다. OCR·복잡한 표/다단 복원은 범위 밖이다.

## 산출물과 추출 검증

- `data/source-v3/authoring/*.md`, `output/pdf/*.pdf`, PDF 작성 도구/글꼴 이름·hash·버전 기록, PDF 대표 입력을 지정한 fixture catalog, snapshot/cache·manifest, extracted/pages·canonical·manifest를 만든다. PDF 스킬에 따라 **모든 출력 페이지를 렌더링하고 직접 확인**한다. Markdown→PDF→추출 사이 숫자·부정·예외·읽기 순서·한글 깨짐/잘림을 대조한다.
- P006의 fixture ID/합성 시간/null URL 규칙, 원본/PDF/캐시 hash·NFC/LF·Unicode code point [start,end)·페이지 map·원자적 새 출력/실패 정책을 계승한다. 실제 Drive 연결이나 업로드는 하지 않는다. 기존 파일을 덮어쓰지 않는다.
- `data/source-v3/policy-map.json`에 기존 출처 commit/path·정책 주장과 새 문서/조항·canonical exact quote/span·페이지/hash·대조 결과를 기록한다. 출처가 없는 새 규정 주장과 빠진 기존 주장이 없어야 한다. 사람 승인 Ground Truth가 아니라 **Codex 원문 보존 대조**임을 명시한다.
- 기존14질문/15fact의 의미를 참조하는 후속 매핑 자료는 원문 재작성 이후에 만들며 새 exact quote/offset/hash를 다시 계산한다. 이전 offset/qrels를 복사하지 않는다. 기존 질문은 관찰된 tuning 자료다. P007은 검색용 질문/정답·holdout을 별도로 확정하고 P013은 사람 승인 Reference Claims를 별도로 확보한다.
- 후속 인계 manifest에 문서6개의 경로·버전/hash, 고정 canonical/page map hash, 정책 대응표, known limitations를 담는다. 같은 파일을 다시 추출한 canonical/page map 내용과 hash가 재현되어야 한다. 시간 등 관측 metadata까지 byte 동일하다고 주장하지 않는다.
