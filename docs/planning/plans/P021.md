## 읽기 화면

- 기본 흐름은 **질문 → 정답 클레임 → 근거 원문**이다. 질문별 번호/탐색 링크를 제공한다. 각 주장에는 쉬운 순번과 문장을 표시하고 바로 아래에 읽을 수 있는 원문 인용·페이지·조항을 펼쳐 보여준다. 같은 주장 목록을 완성 답변으로 다시 반복하지 않는다.
- 처음에는 “원문을 기준으로 정리한 미승인 정답 후보이며, 아래 주장과 근거가 맞는지 확인”이라는 짧은 읽기 안내를 둔다. 각 질문에 승인 검토 기준은 사실/숫자 일치·조건/예외 보존·질문에 필요한 내용의 충분성으로 짧게 표시한다.
- `gt`는 질문/정답 항목, `c`는 주장(청크 아님), 조항 ID와 페이지의 뜻을 한국어로 설명한다. 기술 식별자는 추적 가능하게 유지하되 본문 제목을 코드만으로 채우지 않는다.
- 모델 원응답/수정 이력, 원문 전체, Unicode offset·SHA·JSON·모델 실행 상세는 기본 닫힘 `details` 등으로 분리한다. 키보드로 열고 닫을 수 있게 한다. 근거 인용 자체는 접지 않는다.
- 보고서 하단의 “실험 기록·한계”는 기본 닫힘이다. 펼치면 30회=기본8+반복6+실제질문16, gt09/10은 호출0, 형식28/30·정확인용12/30·실제질문0/8 통과라는 서로 다른 분모를 쉬운 한국어로 먼저 보여준다. 원 JSON과 실패 이력도 남긴다. 과거 측정치와 이번 호출0회를 구분한다.
- 판정 후보18개는 질문/정답지 뒤 별도 구역에 둔다. 근거→주장→제안 판정 순서로 제시하고 E 지지/N 정보 부족/C 모순을 풀어쓴다. 원래 premise/claim/label/ID를 바꾸지 않는다.
- gt09/10은 “문서에 금액 미명시 — 확인 필요”로 표시하고 새 claim·존재하지 않는 인용을 만들지 않는다. 기존 전체 원문/정책 목록 대조 자료를 연결한다. “실제 회사가 지원하지 않는다”로 바꾸지 않는다.
- HTML은 로컬 파일로 직접 읽히며 외부 CDN/서버/모델을 요구하지 않는다. 모바일 폭·줄바꿈·원문 특수문자 escaping·키보드 접기 동작을 확인한다.

나머지 주장은 유지한다. 결과는 질문10개·주장45개·판정 후보18개다. retained claim ID를 재번호하지 않고 화면 표시 순번만 연속으로 보여줄 수 있다. 합친 조건을 “그 직원/해당 휴가”처럼 불명확하게 축약하지 않는다. 이번에 부가 설명을 필수/선택 정답으로 새 분류하거나 질문별 요구 범위를 변경하지 않는다. 조건 묶음의 부분 일치 채점은 P013 상세 정책에서 다룬다.

JSON을 실제로 수정하고 그 JSON에서 HTML을 생성한다. 각 claim의 answer span/source quote·offset·hash를 다시 대조하고 수정된 answer는 주장 목록에서 일관되게 구성한다. 변경 전후 ID·문장·사유·source mapping을 별도 revision 기록으로 남긴다. 단순 숨김으로 JSON의 중복 채점 후보를 남기지 않는다.

## 산출물과 보존

`evaluation/project_b/preparation/`의 보고서/오프라인 revision 기능과 `artifacts/run002/`에 새 패킷·manifest·review.html을 만든다. run002는 새 모델 실험이 아니라 **run001을 근거로 한 검토본 개정**이라고 명시하고 부모 패킷 hash와 실행 이력 참조를 기록한다. run001 전체는 byte-identical로 보존한다. 기존 CLI/검증/보고서 재생은 run001과 새 버전을 구분해 동작해야 한다.

기존 보고서를 덮어쓰는 대신 새 보고서를 사용자에게 열어주고 이전 버전 링크를 제공한다. 새 패킷/HTML hash를 기록하고 모든 승인 상태는 미승인/null로 유지한다. 이전 패킷에 대한 승인 요청은 새 자료의 승인으로 자동 전이하지 않는다. P013은 새 패킷을 검토 대상으로 삼되 실제 승인·준비 검토 전 DRAFT다.

작업 대상 원격은 기존 personal의 plan/dev 브랜치이며 main 승격은 없다. 원문·P007/P017 산출물·기존 모델/ledger·서버·plan의 기존 dirty4파일은 보존한다. 모델 호출/다운로드/서버 재시작은 **0회**다. P013 scoring·NLI·Hybrid·P020 실행은 범위 밖이다.
