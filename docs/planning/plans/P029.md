# P029 — 범용 RAG 학습 화면과 실행·비교 연결

> 준비: 준비 완료
> 실행: 미착수
> 우선순위: 10
> 선행: P028
> 승인 근거: 사용자의 학습용 프론트엔드와 문서·모델·청킹·검색·리랭킹 선택형 실사용 패키지 goal. 2026-11-27 준비 검토 완료. P028 완료 전 실행 대기.

## 목적

P025~P028의 실제 일반 문서 코어를 설치 패키지에서 사용하는 학습 화면으로 연결한다. 고정 HR 전용 P007/P017 UI는 그대로 보존한다. 이 카드는 P008의 실제 평가기·NLI 비교 UI를 조기 완료한 것으로 처리하지 않는다.

## 예정 범위

[UI 실행 계약 v1](../specs/P029-learning-ui-contract.md)과 [준비 검토](../reviews/P029-readiness.md)를 따른다. [화면 설계](../specs/P029-learning-ui-design.md)는 배경이며 실행 미결 사항은 v1 계약이 우선한다. P028 완료 인터페이스/설치 resource는 착수 전에 확인한다. source 선택/업로드·Drive preview/pull, 등록된 local/API LLM 설정 선택, 규칙 청킹3종·검색 문맥 예산, 원문·청크·후보/전달/제외 추적, 기본 답변 preview와 명시 live 실행, 같은 질문·문서의 설정 비교와 저장 이력을 제공한다.

Dense/Hybrid/리랭커/semantic·LLM 청킹/평가기 미연결은 disabled+이유를 표시하며 정상 결과를 만들지 않는다. 추후 준비된 모듈이 추가되면 capability 목록에서 노출한다. 현재 구성만을 최종 goal 완료라고 표현하지 않는다. P013 보류와 Hybrid 선행 순서는 유지한다.

## 준비 검토 결과

P026 result/citation/compare schema와 현재 P027 connector를 읽었고, P028 설치 계약을 기준으로 explicit startup registry·loopback API·single-job/idempotency/restart·기본 preview/명시 live·실제 browser 기준을 확정했다. P028 완료 전 착수하지 않으며 실제 완성본과 차이가 있으면 계약 안의 adapter로 처리하거나 새 범위는 intake한다. 최초 UI는 등록된 LLM/Drive 설정을 선택하며 직접 URL/profile 편집은 후속이고, 이 한계를 전체 goal 완료로 숨기지 않는다. 실제 화면 관찰이 막히면 C4는 미완료로 남긴다.

## 완료 조건

<!-- CHECKLIST:START -->
- [ ] C1: 설치된 패키지의 학습 화면에서 지원 문서·모델 설정·청킹·검색·답변 흐름이 실제 코어와 연결된다.
- [ ] C2: 같은 snapshot·질문의 비교, 원문/청크/실제 전달 근거 추적, 실패·미실행·미지원 표시가 실제 결과와 일치한다.
- [ ] C3: 실행·키·문서 경계와 작업 이력/중복 요청·재시작 동작을 검증하고 기존 단계·P013 보류를 보존한다.
- [ ] C4: 실제 브라우저의 데스크톱/좁은 화면/키보드·핵심 E2E 관찰과 설치·학습 안내·회귀·커밋된 증거를 제공한다.
