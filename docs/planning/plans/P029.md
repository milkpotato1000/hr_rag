# P029 — 범용 RAG 학습 화면과 실행·비교 연결

> 준비: 초안
> 실행: 미착수
> 우선순위: 10
> 선행: P028
> 승인 근거: 사용자의 학습용 프론트엔드와 문서·모델·청킹·검색·리랭킹 선택형 실사용 패키지 goal. 상세 준비 검토 전 실행 불가.

## 목적

P025~P028의 실제 일반 문서 코어를 설치 패키지에서 사용하는 학습 화면으로 연결한다. 고정 HR 전용 P007/P017 UI는 그대로 보존한다. 이 카드는 P008의 실제 평가기·NLI 비교 UI를 조기 완료한 것으로 처리하지 않는다.

## 예정 범위

[화면·실행 흐름 설계 초안](../specs/P029-learning-ui-design.md)을 바탕으로 P028 완료 인터페이스를 확인해 확정한다. source 선택/업로드·Drive preview/pull, 등록된 local/API LLM 설정 선택, 규칙 청킹3종·검색 문맥 예산, 원문·청크·후보/전달/제외 추적, 기본 답변 preview와 명시 live 실행, 같은 질문·문서의 설정 비교와 저장 이력을 제공한다.

Dense/Hybrid/리랭커/semantic·LLM 청킹/평가기 미연결은 disabled+이유를 표시하며 정상 결과를 만들지 않는다. 추후 준비된 모듈이 추가되면 capability 목록에서 노출한다. 현재 구성만을 최종 goal 완료라고 표현하지 않는다. P013 보류와 Hybrid 선행 순서는 유지한다.

## 준비 시 확정

P028 installed resources/CLI와 P027 connector·P026 results의 실제 schema, local server/API/job lifecycle, workspace registry·파일/인증 경계, 명시 실행·재시도 없음, 실제 browser 접근 수단, desktop/mobile/keyboard 관찰 및 자동 UI test 범위를 확정한다. 새 UI의 시각/기능 증거 없이 완료하지 않는다.
