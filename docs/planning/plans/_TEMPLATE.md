# P001 — 작업을 설명하는 한글 제목

> 준비: 초안
> 실행: 미착수
> 우선순위: 10
> 선행: 없음
> 승인 근거: 미확정

## 목적

사용자의 어떤 문제를 해결하며 완료 후 무엇이 가능한지 적는다.

## 기획 준비

기존 근거, 남은 확인·의사결정, 담당과 착수 조건을 적는다.
조건이 채워지면 plan이 준비 검토와 하네스 인계 위임을 근거로 준비 완료·커밋·dev 큐 등록한다.
별도 인계 결재를 반복하지 않는다. 기획·구현에 같은 P번호를 쓴다.

## 범위와 계약

입력·결과·업무 규칙, 데이터/권한 경계, 연결 대상, 제외 범위를 적는다.
검토된 상세 계약이 있으면 링크하며 중복 정의하지 않는다.

## 검증 계획

독립 기대값, 실행 환경, 실패·회귀 사례, 증거 저장 위치와 복구 방법을 적는다.

- [ ] C3: 채택한 plan·구현·검증 근거와 완료 상태가 일치한다.
