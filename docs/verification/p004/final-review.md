# 두 번째 실행 의미 검토 — Codex 원문 대조

검토자는 Codex이며 사람이 검토한 결과가 아니다. 사전 rubric.json의 필수사실·금지오답을 고정하고
05-live-v2 각 질문의 answer/citations/raw_content를 원문과 직접 대조했다. 자동 키워드 점수와 모델 자기평가는 사용하지 않았다.

v2가 의미 정확도를 높였다고 주장하지 않는다. q07 누락이 늘었고 q11의 모델 오류가 사라진 것도 아니다.
q11은 잘못된 인용을 검증기가 막아 최종 오답 대신 보류가 된 사례다. 이 baseline과 실패를 학습 UI에 공개한다.
보류 안내문이 같더라도 model_abstained / invalid_model_response / no_context를 reason/trace로 구분해야 한다.

고정된14개 합성 질문에서 프롬프트를 고친 전후 관측이다. 일반 성능/독립 holdout/사람의 정답 평가가 아니다.
모든 질문 정답을 완료 조건으로 바꾸거나 실패를 삭제하지 않았다. 코어 계약·실제 정상/보류 실행·실패 보존 및 재검증을 완료한 것이다.
