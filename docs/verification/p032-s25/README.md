# 첫 검색에서 기존 로컬 Qwen의 답까지

새로 설치한 실습 환경에서 기본 첫 검색을 끝낸 뒤 practice 폴더에서 아래 명령을 실행했습니다. 첫 설치에는 해시가 고정된 로컬 의존성 wheel을 사용했습니다.

```sh
../env/bin/rag-lab first-answer --execute
```

**질문** 생일 특별휴가는 사용 며칠 전까지 신청해야 하나요?

**실제 답변** “생일 특별휴가는 사용 3영업일 전까지 신청해야 합니다.”

PDF 1쪽 BD-03은 “생일 특별휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 한다.”라고 규정합니다. 모델이 인용한 첫 청크 [320, 720)는 ‘신청하고 팀’까지, 두 번째 청크 [640, 1040)는 같은 조항 전체를 포함합니다. 기한은 두 인용 모두에서 확인했습니다. 두 번째 청크가 2쪽까지 이어져도 신청 기한의 원문 위치는 1쪽입니다. [인용 ID·원문·페이지](review.json) · [터미널에 표시한 결과](cli.log)

첫 검색은 생성 0회였습니다. 명시 실행은 같은 질문과 BM25 인덱스 지문, 전달 청크 5개를 그대로 사용했고 기존 PDF·snapshot·인덱스·첫 검색 결과의 해시는 실행 전후 동일했습니다. 실제 4B 생성은 1회, 재시도 0회였습니다. 서버 호출 전후 모델 식별자, 모델 해제, 소유 서버 종료를 확인했습니다. [호출 기록](ledger.json)

Ollama 연결 실패와 모델 부재는 각각 모의 전송으로 검사했습니다. 두 경우 모두 생성 0회와 준비 방법을 반환했습니다. 실제 결과가 저장된 뒤 같은 명령을 다시 실행했을 때는 기존 출력 오류로 중단됐고 저장된 답변의 해시가 보존됐습니다. [연결 실패](server_off.json) · [모델 부재](model_absent.json) · [공개 첫 설치 안내](../../../README.md#준비된-로컬-qwen으로-첫-답변-받기)
