# 선택한 교육 휴가 PDF의 식별자와 버전 확인

**질문** “교육 휴가 규정의 문서 식별자와 버전은 무엇인가요?”

**실제 답변** “문서 식별자: HR-V3-TRAINING | 버전: 3”

인용한 PDF 1쪽 원문은 “문서 식별자: HR-V3-TRAINING | 버전: 3 | 시행일: 정보 없음”입니다. 식별자의 철자·하이픈과 버전 숫자가 각각 일치했습니다. 모델은 청크 하나를 인용했고, 문자 구간 [0, 202)는 선택한 한 페이지의 원문 전체와 일치합니다. [전체 인용과 쪽수](review.json)

S16과 같은 합성 PDF 바이트와 질문을 사용했습니다. 선택 파일, 실습 사본, 실행 snapshot의 PDF 해시가 일치했습니다. 선택 PDF의 지문은 S16과 같았고 기본 23쪽 규정집과 구별됐습니다. 설치본에서 로컬 모델을 조회하고 BM25와 리랭커 끔을 선택한 뒤, pipeline-setup이 돌려준 경로로 미리보기와 실답변 생성을 진행했습니다. 미리보기의 질문·문서 지문·모델 digest와 실제 전송 내용을 대조했습니다. [선택된 경로](selection.json) · [설치 CLI 미리보기](preview.json)

로컬 Qwen 4B 실제 생성은 1회였습니다. 모델 해제와 소유 서버 종료 후 pipeline-replay로 같은 질문·답변과 인용을 다시 확인했습니다. 기본 규정집의 기존 BM25 인덱스와 S25 첫 답변도 보존됐습니다. 최신 설치 안내가 새 wheel에 포함되는지 확인하고 설치·모델 설정·파이프라인 회귀 검사 11건을 통과했습니다.
