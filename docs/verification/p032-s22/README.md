# 청크 크기, 겹침, 전달 예산이 달라지면 무엇이 바뀔까?

**질문** “생일 특별휴가는 사용 며칠 전까지 신청해야 하나요?” PDF 1쪽 BD-03의 아래 문장은 추출 원문 문자 구간 [684, 734)에 있습니다. 끝 위치는 해당 구간에서 제외합니다.

> 생일 특별휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 한다.

동일 PDF에서 고정 청킹, BM25 후보 상한 20, 최종 K=5, 리랭커 끔을 유지했습니다. 각 행은 기준에서 값 하나만 바꿨습니다. 순위는 위 문장 전체가 들어간 청크의 BM25 순위입니다. [검색 전 고정한 입력](inputs.json)

| 변경 | 크기 / 겹침 / 예산(자) | 청크 수 | 순위 | 실제 전달 | 신청 기한·행위 함께 전달 | 승인까지 전체 문장 전달 |
| --- | --- | ---: | ---: | ---: | --- | --- |
| 기준 | 400 / 80 / 4,000 | 121 | 2위 | 5개 · 2,000자 | 예 | 예 |
| 크기만 축소 | 240 / 80 / 4,000 | 241 | 2위 | 5개 · 1,200자 | 예 | 예 |
| 겹침만 제거 | 400 / 0 / 4,000 | 97 | 1위 | 5개 · 2,000자 | 예 | 예 |
| 예산만 축소 | 400 / 80 / 400 | 121 | 2위 | 1개 · 400자 | 예 | 아니요 |

**크기**를 줄이자 같은 5개를 전달해도 실제 문맥은 800자 짧아졌습니다. 기준의 2위 청크는 [640, 1040), 작은 청크는 [640, 880)로 둘 다 BD-03 전체를 담았습니다.

**겹침** 80자에서는 이 조항 근처의 두 청크가 [640, 720)을 공유했습니다. 겹침을 없애면 [400, 800)에 조항 전체가 들어가 1위였습니다. 이 질문에서는 겹침을 없앤 쪽의 순위가 높았습니다. 다른 질문에서 경계 양쪽에 놓일 내용까지 이 사례로 판단할 수는 없습니다.

**전달 예산** 400자에서는 청크와 BM25 후보 20개의 순위·점수가 기준과 같았습니다. 1위 청크가 예산을 모두 써서 2~5위는 통째로 제외됐습니다. 전달 원문의 끝은 “사용 3영업일 전까지 휴가 시스템에서 신청하고 팀”입니다. 질문이 요구한 기한과 신청 행위는 함께 남았지만, 팀장 승인까지 설명할 근거 문장은 끊겼습니다. 문자 예산에는 시스템 프롬프트 등의 토큰 비용이 포함되지 않습니다. 모델 생성 호출은 0회였고 답변 품질은 미측정입니다. [후보 순위·구간·전달 원문](results.json)
