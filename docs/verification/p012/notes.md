# P012 검증 메모와 한계

- 첫 문서 편집용 heredoc은 시스템 Python의 입력 UTF-8 해석 오류로 파싱 단계에서 종료됐다. 문서 변경 전이었으며 apply_patch와 짧은 후속 편집으로 반영했다. 제품 코드 실패나 테스트 제외가 아니다.
- 브라우저의 summary는 native accessibility에서 button으로 보였지만 Playwright button-role locator는 매칭하지 않았다. 실제 summary 텍스트를 키보드 Enter로 조작해 메뉴를 열고 링크로 이동했다.
- fixture 오류 JSON 다운로드 확인 도구에 긴 응답 공백(약1155초)이 발생했다. 저장 결과는 확인됐고 실제 기본 질문은17.5초로 정상 완료됐다. 이 공백을 제품 속도나 모델 오류로 해석하지 않는다. 이후 현재 QA 동안만 프로세스 범위 idle-sleep 방지를 사용한다. 시스템 설정을 변경하지 않았다.
- P012는 경로/기본값/화면 변경이다. P011의120슬롯 비교를 반복하지 않으며 대표 실제 응답을 원문 및 이전 출력과 대조한다. 기존 연1일 누락은 품질 개선으로 포장하지 않는다.
- 390px/1200px은 생산 HTML/CSS/JS를 srcdoc에 그대로 넣은 별도 로컬 fixture의 실제 iframe viewport다. fixture는 모델 호출0회이고 생산 응답 헤더/CSP를 변경하지 않는다. 화면 폭과 실제 기본/실험 경로의 기능 검증을 구분한다.
