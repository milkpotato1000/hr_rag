# top-k 한 변수 실제 실험 — Codex 원문 대조

질문은 고정 q03, Dense/BGE-M3/Qdrant/Qwen3/system-v2, 문맥8000자, 같은 corpus와 모델digest·sampling 옵션이다.
변경한 입력은 top-k=1/3/5/10뿐이다. 04-k-experiment/k*.json에 실제 HTTP request/result 전체를 저장했다.
같은 장비에서 순차 실행한 한 번의 관측이며 모델 교체/로드가 포함된다. 이 네 개로 보편 지연이나 p95를 주장하지 않는다.

K1의 최종 보류는 모델이 근거 부족을 올바르게 판단한 것이 아니다. 모델은 허구를 생성했고 인용 검증 실패가 이를 막았다.
K3 이후 검색 관련 세 청크가 모두 전달돼도 의미 정확성은 완전하지 않았다. 이 사례에서는 K10이 문맥과 시간을 늘렸지만 필수 조건 누락을 해결하지 않았다.
현재 원문과 P004 사전 rubric으로 Codex가 대조한 검토이며 사람 검토/키워드 점수/생성 모델 자기평가가 아니다.

retrieval-replay-metrics.json은 P003에 저장된 **기존 실제 Dense 순위**를 P001 평가기로 K1/3/5/10에 재평가한 것이다.
새14질문 실시간 검색으로 표시하지 않는다. 위 생성 실험은 별도의 실제 q03 HTTP 실행이다.
질문 원문·모델digest·system hash·corpus hash·문맥예산/옵션이 같음을 comparison.json에서 검증한다.
