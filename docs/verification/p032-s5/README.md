# 같은 근거로 생성 모델 설정 비교하기

**질문** 생일 특별휴가는 사용 며칠 전까지 신청해야 하나요?

**로컬 Qwen 4B의 실제 답변** “사용 3영업일 전까지”

규정집 PDF 1쪽 BD-03은 사용 3영업일 전까지 휴가 시스템에서 신청하도록 규정한다. 답변은 질문에서 묻는 신청 시한을 정확히 제시했다. 인용 2개의 원문과 페이지별 문자 위치를 대조했다. 첫 인용에는 신청과 승인 규정 전체가 들어 있고 두 번째 인용은 신청 기한을 포함한 채 문장 중간에서 끝난다. 두 청크가 겹치는 구간이 같은 규정을 뒷받침한다. 첫 청크는 2쪽까지 걸치지만 기한을 규정한 문장은 1쪽에 있다.

| 생성 설정 | 저장 상태 | 생성 요청 | 입력 / 출력 토큰 | 관측 지연 |
| --- | --- | ---: | --- | --- |
| Ollama Qwen3-4B-Thinking-2507, Q4_K_M | answered | 1 | 2,335 / 2,078 | 134.82초 |
| OpenAI Chat 예시 프로필 | preview · 답변 없음 | 0 | 미측정 | 미측정 |

두 행은 S4에서 Hybrid 후보 20개를 mMiniLM으로 재정렬한 뒤 선택한 동일한 5개 청크를 사용한다. 질문과 공통 업무 지시도 같다. 요청 본문의 공급자별 필드 차이는 저장 결과에 표시된다. 이 표에서 실제 생성 품질을 관찰한 모델은 하나다. 비용은 미측정이다.

새 wheel을 독립 환경에 설치해 preview와 실제 로컬 실행을 검증했다. 비교 명령은 저장된 결과만 읽는다. 호출 한도 시험 8건, 재정렬·비교 회귀 21건, provider 회귀 18건과 설치 리소스 3건을 통과했다. 시스템 Python으로 처음 실행한 회귀는 pathlib 버전 차이로 실패해 설치본의 Python 3.12로 검증했고, 샌드박스에서 포트 바인딩이 거부된 두 provider 시험은 소유 loopback 시험 서버로 검증했다. S4 원본 해시, 모델 언로드, 소유 Ollama 서버의 종료를 확인했다.
