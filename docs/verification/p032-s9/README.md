# 설치본 UI에서 규정집 답변과 인용 열기

‘문서에서 답변까지’에서 PDF와 질문, 청킹·검색·재정렬·생성 설정을 고르고 ‘선택 구성 미리보기’를 누른다. 모델별 전송 주소와 호출 상한을 읽은 뒤 실행 권한이 있는 서버에서 ‘이 구성으로 실제 실행’을 선택한다. 저장 결과는 ‘저장 결과 열기’에서 바로 읽는다. [serve 명령과 단계별 실습](../../../rag_package/resources/sample/HANDBOOK.md)

| 브라우저에서 확인한 항목 | 관찰 결과 |
| --- | --- |
| 규정집 계층 + E5 Hybrid + mMiniLM + Qwen 미리보기 | 독립 설치 CLI와 입력·예정 작업·전송 주소가 일치. 실제 모델 호출 0 |
| S8의 저장된 실답변 | “3영업일 전”. 인용을 펼치면 제1장 → 제1절 → BD-03 신청 기한과 승인, PDF 1쪽, 원문 범위 [668, 961), 규정 원문을 읽을 수 있음 |
| 세부 실험 이동 | 청킹 메뉴를 열었다가 통합 실행으로 돌아와 검색과 재정렬 선택을 변경 |
| BM25 + 재정렬 끔, 시험 실행 | 새로고침 뒤 같은 작업의 ‘시험 어댑터의 합성 답변’ 표시. 합성 생성 요청 1회 |
| 시험 어댑터 오류 | 별도 질문에서 의도적으로 잘못된 응답을 주자 answer 단계의 provider_invalid_response와 ‘생성된 답변 없음’ 표시. 합성 요청 1회 |

S8 결과는 같은 실습 폴더에 복사한 뒤 파일 전체 바이트가 원래 실행과 같은지 확인했다. 이번 단계에서 실제 모델·유료 API·Drive·평가기 호출은 0회다. 시험 어댑터의 성공·실패는 UI 동작 검증용이다.

권한 누락, 같은 요청 ID의 중복 제출, 실행 중 별도 요청, 작업 완료 뒤 재접속과 재제출을 시험했다. 동일 요청에서 합성 POST는 1회였다. 신규 작업 시험 2건과 기존 UI·설치·파이프라인·청킹·재정렬 회귀 55건을 통과했다. [실제 브라우저 작업 검증](verified.json) · [기존 실답변의 PDF 대조](../p032-s8/README.md)
