# 가상 회사 생일 휴가 안내

학습용 가상 문서이며 실제 회사 정책이 아닙니다.

## 자격과 제외

생일 휴가 대상은 입사 후 3개월이 지난 재직자입니다. 수습 중인 직원은 대상에서 제외합니다. 생일 휴가는 매년 1일 신청할 수 있습니다. 입사일과 수습 여부는 신청 전에 인사 기록에서 확인합니다. 담당자는 확인한 기준일을 신청 기록에 남깁니다. 정보가 서로 다르면 자동 승인하지 않고 기록을 확인한 뒤 처리합니다.

## 신청 절차

생일 휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 합니다. 직원은 사용하려는 날짜와 휴가 종류를 확인합니다. 잘못된 종류로 접수했다면 기존 신청을 정정한 뒤 승인 요청을 보냅니다. 팀장은 승인 여부와 처리 시간을 기록합니다. 화면에 승인 완료가 보이지 않는다면 신청자에게 확인을 요청합니다.

## 사용 기간

생일 휴가는 생일이 속한 달의 근무일에 사용합니다. 해당 월을 넘겨 이월하거나 현금으로 지급하지 않습니다. 신청자가 날짜를 바꿀 때도 사용 가능한 달과 근무일 조건을 다시 확인합니다. 담당자는 이전 날짜와 변경한 날짜를 구분해 기록합니다. 다음 달의 일반 연차 신청과 생일 휴가 신청을 혼동하지 않도록 휴가 종류를 확인합니다.
