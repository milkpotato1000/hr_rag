# P011 답변 의미 검토

검토 주체는 Codex다. 생성 모델 자기평가를 사용하지 않고 원문·최종 답변·선택 인용을 대조했다. 각 반복의 출력 hash를 수동 검토한 대표 출력과 대조해 동일할 때만 같은 판정을 적용했다. 상세 사실·주장·근거는 manual-reviews.json, 120개 슬롯은 quality-review.json에 있다.

| 지표 | Direct 60회 | LangChain 60회 |
| --- | ---: | ---: |
| 필수 사실 충족 | 159/186 | 159/186 |
| 필수 사실을 모두 담은 답변 | 30 | 30 |
| 부분 답변 | 15 | 15 |
| 과도 보류 | 3 | 3 |
| 적절 보류 | 12 | 12 |
| 선택 인용의 주장 지지 | 171/177 | 171/177 |
| 실행 오류 / 모순 / 허구 주장 | 0 / 0 / 0 | 0 / 0 / 0 |

이 합계로 질문별 저하를 상쇄하지 않는다. 각 20개 case의 3회 지표도 따로 비교한다. 양쪽 모두 다음 한계가 남았다.

- q03: 연 1일이 인용에는 있지만 답변 본문에는 없다. 필수 사실 8/9.
- q07: 현장 장비 운영 직무 제외와 승인 주체 팀장을 생략했다. 4/6.
- q08: 회사 기기·VPN·공용PC 금지 근거가 전달됐는데 보류했다. 0/3, 과도 보류.
- q09: 별도 신청을 명시하지 않았다. 3/4. 팀장 승인 근거 birthday-request가 전달됐지만 선택 인용에는 없어 주장 지지 4/5.
- 식대 BM25: 미지원은 맞지만 사전 종합 rubric의 출근일 1만원은 본문에 없다. 2/3. 질문 자체의 범위보다 넓은 rubric임을 함께 읽어야 한다.
- c01: 필수 사실 4/4지만 덧붙인 연차 2영업일 전 신청의 선택 인용이 없다. 주장 지지 7/8. 추가 생일 자격 설명은 수습 예외도 생략했다.
- c02: 시작 전 인사 담당자에게 등록 주소 변경 요청은 맞다. 등록 자택으로 장소를 제한한다는 규정은 명시하지 않아 3/4로 평가했다.

필수 사실 충족과 인용 지지는 별도 지표다. 전체 원문 인용을 보여주는 것만으로 본문의 누락이 해결되지는 않는다. 나머지 원문·PDF 질문은 고정한 필수 사실을 충족했고, 근거 없는 네 질문은 모두 적절히 보류했다.

이 결과는 원문 15개·PDF 청크 20개, 기존에 관찰한 14질문과 작은 추가 확인 세트에 한정된다. 충분한 독립 holdout이나 모든 질문에 대한 통계적 동등성을 주장하지 않는다. 절전 영향을 받은 그룹의 양쪽 전체 반복 재측정은 controlled-comparison.json에서 별도로 확인한다. 원래 cold 오류 네 건은 이 warm 의미 표에 섞지 않고 초기 안정성 실패로 보존한다.
