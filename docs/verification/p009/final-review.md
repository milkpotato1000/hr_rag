# P009 실제 답변 원문 대조

검토자: Codex. 사람 검토나 생성 모델 자기평가가 아니다. `rubric.json`은 이번 생성 전에 P004 기준을 계승해 저장했다. 기존 기본 corpus의 명료화된 이월 문구를 사용했으며 평가 중 문서/모델/검색 설정을 바꾸지 않았다. 기본 14질문은 Dense top-k5, 문맥 8000자, timeout120초, temperature0/seed42이다. 별도 식대 smoke만 BM25 top-k5다.

14질문 결과는 답 가능 11개 중 **정확7 / 부분3 / 과도보류1 / 오답0 / 장애0**, 근거 없음3개는 **적정보류3**이다. 모든 14개 원응답은 새 JSON/ID 구조 검증을 통과했다. answered 10개 모두 원문 전체와 UTF-8 바이트가 동일하지만, q09의 선택 인용은 답변의 팀장 승인 주장을 다 덮지 못한다. 따라서 인용 구조 통과율과 의미 지지율을 하나로 합치지 않는다.

## 필수 식대 및 PDF 사례

- `live/meal-bm25.json`: 최초 P009 BM25 top-k5 실행에서 welfare-meal 전달/선택, answered. 재택·휴가일 모두 미지원이라는 목표 의미를 충족했고 코드 인용은 welfare-meal 전체와 동일하다. 사무실 출근일 1만 원은 이 smoke의 answer에 없으며 인용에만 있다. 14질문 전체 rubric의 q10(Dense) 실행에서는 금액도 답했다. 보고된 예전 “휴:” 오류를 이번 실행에서 재현했다고 주장하지 않는다.
- `live/pdf-q06.json`: source-v2 Dense top-k5, answered. 최대 5일분·다음 해3월31일·생일 특별휴가 적용 제외를 정확히 답했다. 첫 선택 청크가 전부 지지하고, 두 번째는 겹치는 이월 내용 일부를 포함해 추가 선택됐다. quote의 `기한\n은`, 페이지 바닥글·앞뒤 잘린 문장·공백도 원문 그대로다. 모델이 문장을 복사하지 않으므로 P006 q06에서 발생한 PDF 줄바꿈 손실이 없다. 전체 청크 인용은 문장 단위 최소 근거 인용이 아니며 주변 내용도 표시한다.

## 이전 결과와 비교할 때

P004 v2 기록은 정확5/부분2/과도보류4였다. 이번 실행의 정확7/부분3/과도보류1과 수치가 다르지만 프롬프트와 출력 schema가 동시에 바뀌었고, P004 이후 연차 문구 명료화도 있었다. 고정 seed도 생성 바이트를 보장하지 않는다. 이 작은 단일 실행을 일반 정확도 향상이나 인과효과로 해석하지 않는다. P004~P006 카드/실패 기록은 수정하지 않았다.

남은 학습·평가 포인트는 q03/q07의 조건 누락, q08의 근거가 있는데 보류, q09의 유효하지만 불완전한 근거 선택이다. 이들은 ID/원문 조립 검사로 해결되지 않는다. P007/P008 초안은 자동 실행하지 않는다.
