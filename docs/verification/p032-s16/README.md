# 내 PDF에서 찾은 근거 확인하기

배포 규정집과 별개인 합성 교육 휴가 PDF를 선택하고 **“교육 휴가 규정의 문서 식별자와 버전은 무엇인가요?”**를 물었습니다. 새 설치본에서 BM25가 반환한 첫 청크는 PDF 1쪽 원문과 일치했습니다.

> 문서 식별자: HR-V3-TRAINING | 버전: 3 | 시행일: 정보 없음

교육 휴가 PDF와 기본 규정집의 SHA-256 및 snapshot 지문이 서로 다릅니다. 기본 규정집의 추출 본문에는 이 식별자가 없습니다. 선택 파일·원본·기본 PDF와 기존 모델 프로필의 해시를 준비 전후 대조했습니다. [원문·페이지와 지문](verified.json)

브라우저에서 ‘자격시험 교육 휴가 규정’과 위 질문이 미리 선택됐습니다. 질문을 ‘교육 휴가 규정은 몇 버전인가요?’로 수정하고 다시 미리보기했을 때도 같은 PDF와 설정이 사용됐습니다. 두 UI 결과를 설치 CLI의 전체 계획과 대조했습니다. 답변 생성과 외부 전송은 0회였습니다.

공백·작은따옴표가 있는 원본 경로, UTF-8 TXT와 Markdown, 합성 표시 및 제목 기본값을 확인했습니다. 누락 파일·지원하지 않는 형식·기존 출력 폴더를 거부했고, 이전 검색 구성 여섯 개의 설치 CLI 미리보기 결과도 재현했습니다.
