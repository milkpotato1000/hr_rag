# 설치본의 첫 규정집 검색

“생일 특별휴가는 사용 며칠 전까지 신청해야 하나요?”를 기본 예제 PDF로 검색했습니다. BM25가 전달한 청크 5개 중 2번째에 PDF 1쪽 BD-03의 다음 문장이 들어 있었습니다.

> 생일 특별휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 한다.

기한은 휴가 시스템에서 **신청하는 시점**에 적용됩니다. 같은 조항은 팀장 승인도 요구합니다.

새 가상환경에 sdist에서 빌드한 wheel을 설치하고 소스 트리 밖에서 init과 설치된 HANDBOOK.md의 검색 명령을 실행했습니다. 원본·wheel·실습 폴더 PDF 바이트가 일치했습니다. PDF 리더는 이전 검증 환경의 pypdf 6.21.2를 오프라인으로 재사용했습니다. 기존 텍스트 예제의 snapshot도 생성했습니다. 사용자 PDF가 있는 폴더에 다시 init을 요청하면 output_exists로 종료했고 해당 PDF의 전후 SHA-256이 일치했습니다. [실행 명령·해시·관찰값](verified.json) · [검증 코드](verify.py)

이번 검색의 생성 호출은 0회입니다. 같은 질문에 대한 로컬 Qwen 4B의 기존 답변은 “3영업일 전”이었습니다. 이 답변은 E5 Hybrid 검색과 mMiniLM 리랭킹을 거친 문맥에서 생성했습니다. [실제 답변과 PDF 인용](../p032-s8/README.md) · [설치 UI 재생](../p032-s9/README.md)
