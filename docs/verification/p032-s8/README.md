# 선택한 구성으로 규정집 PDF부터 답변까지

**질문** 생일 특별휴가는 사용 며칠 전까지 신청해야 하나요?

**로컬 Qwen 4B의 실제 답변** “3영업일 전”

질문과 함께 읽으면 신청 시점의 영업일 수가 맞다. 답변 자체에는 ‘사용’과 ‘까지’가 생략됐다. PDF 1쪽의 BD-03은 “생일 특별휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 한다.”라고 규정한다. 정확한 의미는 **사용일 기준 3영업일 전까지 신청**하는 것이다.

| 단계 | 실제 확인 결과 |
| --- | --- |
| 원문·청킹 | 같은 PDF에서 새 snapshot을 만들고 handbook-v1 400/80으로 177개 청크를 생성 |
| 검색 | 기존 E5 로컬 파일로 문서 색인 1회·질의 임베딩 1회. Hybrid 후보에서 BD-03은 2위 |
| 재정렬 | 같은 후보 20개를 mMiniLM으로 1회 채점. BD-03이 1위로 올라와 최종 5개에 포함 |
| 생성 | 해당 문맥으로 기존 로컬 4B를 1회 호출. 입력 1,934토큰, 출력 965토큰, 생성 요청 경과 66.09초 |
| 인용 | 인용 1건의 ID가 새 계층 청크와 최종 문맥 양쪽에 있음. 경로는 제1장 생일 특별휴가와 포인트의 구분 → 제1절 적용 기준 → BD-03 신청 기한과 승인 |
| PDF 대조·재생 | 인용문 전체가 PDF 1쪽의 정규화 문자 범위 [668, 961)와 일치. 설치 CLI로 저장된 최종 결과를 재생하고 원본 결과와 대조 |

기본 명령은 입력과 전송 대상·작업량·출력 위치를 보여주는 미리보기다. 명시 실행은 새 디렉터리에 단계별 산출물을 남기며 실패 시 후속 단계를 실행하지 않는다. 사용한 로컬 모델은 언로드됐고 검증을 위해 시작한 서버는 종료했다. 유료 API는 합성 설정의 미리보기만 시험했다. 단일 질문 실측이며 다른 질문의 답변 품질은 이 결과에서 측정하지 않았다.
