# 브라우저에서 생일 특별휴가 승인권자 묻기

**질문** “생일 특별휴가를 신청하면 누구의 승인을 받아야 하나요?”

**로컬 Qwen 4B의 실제 답변** “팀장”

PDF 1쪽 BD-03에는 “생일 특별휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 한다.”라고 적혀 있습니다. 답변은 질문이 요구한 승인권자를 정확히 짚었습니다.

| 확인한 단계 | 관찰값 |
| --- | --- |
| 설치 화면 | 새 실습 폴더에서 기본 규정집 PDF, 고정 청킹 400자·겹침 80자, BM25, 리랭커 끔, 로컬 Qwen 4B를 선택한 상태로 시작 |
| 미리보기 | 기본 신청 기한 질문을 승인권자 질문으로 변경. 예정 답변 1회, 실제 전송 0회. [미리보기 기록](preview-job.json) |
| 실제 입력 | 브라우저의 실제 실행 버튼을 한 번 눌렀고, 전송 본문에 변경한 질문과 청크 5개가 포함됐고 첫 청크에 BD-03 문장이 있었음. [전달한 문맥](dispatch.json) |
| 생성 | 작업 b2e50490df664ca094a75305e2d5df4b 완료. 실제 생성 1회, 재시도 0회. 생성 요청 72.02초, 입력 2,392토큰, 출력 1,011토큰. [작업](live-job.json) · [모델 응답·인용](result.json) |
| 재열기 | 저장된 answered 결과를 선택해 열고 인용을 펼침. 같은 답변과 원문 문자 범위 [640, 1040)을 확인. 청크가 1~2쪽에 걸쳐 있어 화면은 두 페이지를 표시하며 승인 조건 문장은 1쪽에 있음. [원문 대조](review.json) |
| 종료 | 설치 UI 종료, 모델 언로드 및 정상 메모리 압력 30초 확인 후 작업 소유 Ollama 서버 종료. [종료 기록](server-closed.json) · [호출 기록](ledger.json) |

같은 설치물로 따라 하려면 HANDBOOK.md에서 로컬 모델 프로필을 준비한 뒤 실습 폴더에서 아래 명령을 실행하세요. 터미널에 표시된 주소의 **문서에서 답변까지**에서 질문을 바꾸고 미리보기 → 실제 실행 → 저장 결과 열기 순으로 확인합니다.

```sh
rag-lab serve --workspace . --sources handbook-sources.json --llm-config handbook-model.json --chunk-config chunk-fixed.json --allow-model-execution
```
