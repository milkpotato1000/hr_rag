# 청킹을 바꿔도 승인권자 답변이 달라질까?

**질문** “생일 특별휴가를 신청하면 누구의 승인을 받아야 하나요?”

| 관찰 항목 | 고정 400자·겹침 80자 | 재귀 400자·겹침 80자 |
| --- | --- | --- |
| 로컬 Qwen 4B의 실제 답변 전문 | 팀장 | 팀장 |
| BD-03 승인 문장이 들어간 첫 전달 순위 | 1위 / 5개 | 1위 / 5개 |
| 모델이 인용한 청크의 문자 범위 | [640, 1040) | [513, 851) |
| 인용 청크가 걸친 PDF 페이지 | 1~2쪽 | 1쪽 |
| 입력 / 출력 토큰 | 2,392 / 1,011 | 2,094 / 1,073 |
| 생성 요청 경과 시간 | 72.02초 | 72.43초 |

PDF **1쪽 BD-03 신청 기한과 승인**에는 “생일 특별휴가는 사용 3영업일 전까지 휴가 시스템에서 신청하고 팀장의 승인을 받아야 한다.”라고 적혀 있습니다. 두 실행 모두 승인권자를 정확하게 답했고 그 문장을 포함한 청크를 인용했습니다. 고정 청크에는 2쪽의 다음 조항까지 들어갑니다. 재귀 청크는 1쪽 안에서 끝납니다. 이 질문에서는 **근거가 1위에 유지됐고 입력이 298토큰 줄었으며 답변은 같았습니다.** [양쪽 인용 전문과 전달 문맥 5개씩 펼쳐 보기](report.html) · [저장된 S12 비교 결과](comparison.json)

## 무엇을 고정했나

기존 고정 청킹 답변은 S11 브라우저 실험에서 읽었습니다. 재귀 청킹은 독립 설치본의 pipeline CLI에서 한 번 생성했습니다. 같은 합성 PDF와 질문, BM25 후보 20개·최종 5개·문맥 예산 4,000자, 리랭커 끔, 같은 Qwen 4B digest를 확인했습니다. 실제 요청에서 달라질 수 있는 청크 목록과 거기에 대응하는 인용 허용 ID를 분리한 뒤 나머지 요청 전체를 대조했습니다. 시스템 지시, JSON 형식, 모델 옵션과 질문이 같았습니다. 재귀 요청 본문도 전송 직전에 사전 계산한 해시와 일치했습니다. [입력 해시와 옵션](inputs.json)

패키지 버전은 양쪽 모두 0.1.0.dev1이지만 wheel 해시는 다릅니다. 고정 실행은 S10 wheel의 UI 경로, 재귀 실행은 S12 wheel의 CLI 경로입니다. S11 실행 파일에는 후속 버전에서 추가한 전체 프로필 필드가 없어 S12 비교기의 판정은 **incomplete_settings**입니다. 위 대조는 별도로 보존한 실제 요청과 입력에서 확인한 항목에 한정됩니다. 이 결과는 한 질문의 실행 두 건에서 얻은 관찰입니다. [답변·원문 일치와 실행 관찰값](observations.json)

새 체크아웃에서 이 페이지와 report.html을 읽을 때 모델이나 실습 환경은 필요하지 않습니다. HTML 파일 하나를 로컬 브라우저로 열면 양쪽 근거를 펼칠 수 있습니다.
