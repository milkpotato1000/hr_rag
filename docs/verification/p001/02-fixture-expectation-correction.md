# 최초 검증 후 수정

첫 검증에서 19개 테스트 중 1개가 실패했다. 원본 출력은 `01-initial-tests.txt`에 보존한다.

평가기 산식이나 corpus·질문·순위는 변경하지 않았다. 아래 표를 원본 qrels와 순위에 대조해 재계산했다.

answerable 분모는 11. 따라서 Precision@5 = 17/55, MRR@5 = 25/33이다.
첫 실패의 Precision 기대값 18/55와 아직 도달하지 않았던 MRR 기대값 47/66을 이 독립 합산값으로 수정했다.
계약 예시 `{a:3,b:1}`, `[x,b,a]`의 K=2/5 독립 산식 검증은 첫 실행부터 통과했다.
수정 후 전체 재검증 결과는 `03-final-tests.txt`에 기록한다.
