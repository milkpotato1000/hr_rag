# 같은 규정집에서 신청 기한 근거의 순위 비교

“생일 특별휴가는 사용 며칠 전까지 신청해야 하나요?”에 대해 BM25, E5 Dense, E5 Hybrid 모두 PDF 1쪽 BD-03의 “사용 3영업일 전까지 휴가 시스템에서 신청”을 1위에서 찾았다. 고정 400자에 80자를 겹쳐서 만든 두 청크가 이 구절을 공유한다. 한 청크는 “신청하고 팀”에서 끝나고, 다른 청크에는 “팀장의 승인을 받아야 한다”까지 들어 있다.

| 설치본 경로 | 신청 기한의 첫 순위 | 승인까지 포함한 완전한 문장의 순위 | 완전한 문장을 최종 문맥에 전달 |
| --- | ---: | ---: | --- |
| BM25 | 1 | 2 | 예 |
| E5 Dense | 1 | 2 | 예 |
| E5 Hybrid (RRF) | 1 | 2 | 예 |
| Hybrid 후보 20개, 원래 순위 | 1 | 2 | 예 |
| 같은 후보 20개, mMiniLM 리랭커 | 1 | 1 | 예 |

완전한 문장은 PDF 1쪽에 있다. 그 청크의 뒷부분이 다음 페이지로 이어져 청크 메타데이터에는 1·2쪽이 함께 표시된다. 이번 질문에서 리랭커는 설명이 더 완전한 근거를 먼저 보여줬다. 신청 기한에 답할 수 있는 근거는 모든 설정에서 이미 최종 문맥에 들어 있었다. 최종 K는 5, 예산은 4,000자다. S4에서는 생성 호출 없이 실제 전달 예정 문맥까지 확인했다. 답변과 인용이 궁금하면 [S3의 단일 질문 실답변](../p032-s3/report.html)을 읽으면 된다.

새 가상환경에 새 wheel을 설치하고 동일 머신에 준비된 고정 SDK와 PDF reader를 재사용했다. E5 인덱스 계산 1회, 질의 계산 2회, mMiniLM 20쌍 계산 1회로 끝났다. 관측된 개별 worker 최고 RSS는 약 0.93 GiB였다. 이 수치는 해당 머신과 문서·질문 한 건의 관측치다. BGE 대안은 설정 교체 방법만 안내한다.
