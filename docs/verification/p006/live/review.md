# 실제 모델 smoke 대조

검토자는 Codex이며 사람 검토/생성 모델 자기평가/키워드 점수가 아니다. 원문 기반 평가 spec은 첫 생성 전에 작성했다. 모든 실행은 BGE-M3·Qwen3 잠금, system-v2, Dense top-k 5, context 8000을 유지했다. 14개 전체 품질 측정이 아니라 기능 smoke다.

| 실행 | 실제 결과 | 원문 대조 |
| --- | --- | --- |
| q06 (기존 질문 그대로) | invalid_model_response로 보류 | 관련 연차 문서가 1위이고 답변 초안의 5일분/3월 31일 의미는 맞음. 두 quote에서 원문 줄바꿈을 생략해 정확 부분 문자열이 아님. 인용 검증 단계 실패, 근거 없음으로 세지 않음. |
| q13 (기존 질문 그대로) | model_abstained | 퇴직금 공식 근거가 없으므로 적절 보류. 근접 검색 후보가 있다는 사실만으로 공식 생성하지 않음. |
| q04 의미 동등 smoke 질문 | answered | 실제 질문은 “입사 1년 미만 직원의 연차는 어떻게 발생하나요?”로 기존 q04의 “언제 생기나요?”와 다름. 한 달 개근 시 1일이라는 필수 조건과 양을 정확히 설명하고 PDF page 1의 문장을 그대로 인용. 고정 14질문 점수로 집계하지 않음. |

q06을 맞추려고 문서/질문/정답/인용 검증/프롬프트를 바꾸지 않았다. 계약의 기능 완료 기준은 최소 근거 답변 1개와 적절 보류 1개이며 q04와 q13으로 확인한다. q06의 실제 실패는 후속 정규화/인용 정책과 답변 품질 비교의 입력으로 보존한다.
