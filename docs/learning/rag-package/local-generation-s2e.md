# 같은 생일휴가 질문으로 로컬 Thinking 모델 검증하기

[질문·최종 답변·근거 대조](../../verification/p032-s2e/report.html) · [첫 실행 기록](local-generation-s2d.md)

질문은 “생일 특별휴가는 누가 며칠 받을 수 있고, 언제까지 신청해서 언제 사용해야 하나요?”입니다. 저장된 청크 5개, 총 1,280자에는 재직 3개월, 수습 제외, 연간 1일, 생일이 속한 달, 근무일, 사용 3영업일 전 신청이 모두 들어 있습니다. 검색을 다시 실행하면 입력까지 달라질 수 있어, 두 실행에 동일한 질문과 문맥을 사용했습니다.

| 설정 | 첫 실행 | 후속 실행 |
| --- | --- | --- |
| 로컬 모델 | 기존 Qwen3-4B-Thinking-2507, Q4_K_M | 동일 digest |
| Ollama `think` | false | true |
| temperature | 0 | 0.6 |
| 최대 출력 토큰 | 1,024 | 4,096 |

Ollama 프로필의 `think` 기본값은 false입니다. 이 모델처럼 추론 전용 모델을 선택하면 로컬 설정에 `"think": true`를 명시할 수 있습니다. 패키지는 별도 필드에 온 추론문을 폐기하고 최종 본문에서 JSON 구조와 인용 ID를 검사합니다. UI와 보고서에는 공개할 수 있는 최종 답변만 표시합니다.

Ollama가 제공하는 출력 토큰 수는 응답 전체의 합계입니다. 추론과 최종 답변 각각의 토큰 수는 미측정입니다. 첫 실행에서 확인한 사실은 1,024토큰 상한과 잘림입니다. 같은 질문을 사용했어도 모델 모드·온도·출력 상한을 함께 바꿨으므로 결과 차이를 어느 한 설정의 효과로 단정할 수 없습니다.

## 관측 결과

첫 실행은 출력 상한에서 잘렸고, 이번 실행은 정상 종료 후 답변 형식 검사에서 중단됐습니다. Ollama 호출 전후 모델 식별값이 일치했고, 1,778토큰 입력에 1,987토큰을 출력한 뒤 stop으로 끝났습니다. 모델 응답 시간은 약 126초입니다. 최종 본문은 JSON 파싱을 통과했지만 답변 구조 검사에서 invalid_answer_schema로 중단됐습니다. 저장된 오류만으로 위반 필드나 이유를 특정할 수 없습니다. 유효한 답변이나 인용이 게시되지 않아 필수 조건 누락·추가 주장·인용 지지 여부는 평가할 수 없습니다. gt02~gt10은 미실행입니다.
