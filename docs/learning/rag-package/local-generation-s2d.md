# 로컬 4B 첫 답변: 근거가 있어도 생성이 끝나지 않을 수 있다

[학습 시작점](README.md) · [실제 보고서](../../verification/p032-s2d/report.html)

기존 Qwen4B로 실제 답변 생성까지 연결했지만, 첫 생일휴가 문항에서 **출력 상한1,024토큰에 도달해 중단**했습니다. 유효 답변0개, 이후9문항은 미실행입니다. 이 결과를 답변 품질0점이나4B 전체 실패로 일반화하지 않습니다.

| 단계 | 관측 | 의미 |
| --- | --- | --- |
| 검색·문맥 | 기존 E5 Hybrid/none 결과5청크·1,280자를 재사용. 생일휴가 필수 근거6/6 포함 | 필요한 근거가 전달되지 않은 실패는 아님 |
| 실제 생성 | 입력1,778토큰, 출력1,024토큰, 약87.47초 | 출력 상한에 도달했고 finish_reason=length |
| 제품 결과 | provider_truncated, answer=null | 미완성 응답을 유효 JSON 답변으로 채택하지 않음 |
| 정리 | 모델 해제, normal 복귀, 작업 소유 서버 종료 | 다음 요청을 자동으로 보내지 않음 |

볼 포인트는 **근거 회수 → 생성 정상 종료 → 답변 내용 → 인용 지지**의 구분입니다. 이번에는 생성 정상 종료에서 막혔으므로, 원문 인용을 더 붙이는 것만으로 해결됐다고 볼 수 없습니다. 유효 답변이 없으니 “연간1일을 누락했다” 같은 내용 판정도 할 수 없습니다.

출력 토큰 상한과 입력 문맥 한도는 다릅니다. 이번 `num_ctx=8192`는 실행 설정이며 실제 입력은1,778토큰이었습니다. 출력1,024토큰을 모두 사용한 이유가 장황함·반복·thinking 중 무엇인지는 정규화된 실패 기록만으로 단정하지 않습니다. raw 미완성 응답이나 hidden thinking을 복원해 분석 자료로 쓰지 않았습니다.

다음 실험에서 검토할 변수는 출력 상한과 응답 길이 지시입니다. 하나를 바꾸면 원래 조건과 별도 실험으로 남겨야 합니다. 상한 증가는 시간·자원도 달라지므로 무조건 정답률 개선으로 해석하지 않습니다. 현재는 기존 실패·1회 사용·나머지 미실행을 보존하고 후속 계획을 기다립니다. 모델·prompt·parser를 임의로 바꾸거나 같은 요청을 재시도하지 않았습니다.

이 단계는 dev Codex의 원문 대조와 실행 관찰입니다. 자동 LLM/NLI 평가기는 실행하지 않았으며 Drive와 LLM 청킹도 보류입니다. [세부 검증 기록](../../verification/p032-s2d/README.md)에 설정·identity·자원·한계를 남겼습니다.
